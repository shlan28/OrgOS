# loom-ui-mock

用 React 模拟 macOS 风格 "Loom" AI 编程助手应用界面（依据截图 `截屏2026-08-26 13.18.01_1.png` 还原）。

> 创建日期：2026-08-26
> 更新日期：2026-10-22（窗口贴边占满桌面（padding 24→6px）；格 1 标题改「项目名 · 会话」+ 编辑项目铅笔 icon 迁入格 1 头部（格 2 删编辑按钮）；技术方案见 `docs/项目中心-详情页四格布局-技术方案.md`）

## 技术栈

- React 18 + TypeScript
- Vite 5
- CSS（组件级样式，无 UI 库依赖）

## 运行

```bash
npm install
npm run dev      # 开发模式，默认 http://localhost:5173
npm run build    # 生产构建
npm run preview  # 预览构建产物
```

## 界面还原内容

- 窗口外壳：圆角窗口 + macOS 交通灯按钮 + "Loom" 标题 + 侧边栏切换图标
- 左侧边栏：Home/Code 分段控件（Code 选中态）、新对话、定制、**项目中心**、项目区（loomweb + 空状态提示）、底部用户 shilu
- 主内容区：右上角**多视窗 btn**（田字格 icon，激活态高亮 + 窗格数角标）、大标题"要在 loomweb 中构建什么？"、圆角输入卡片
- **首页多视窗（2×2 四窗格）**：点右上角多视窗 btn → 主区切分四窗格，**当前会话（新对话）进左上**（绿描边聚焦，点击窗格切换聚焦）；再点 btn 恢复单窗口（窗格分配保留，重进不丢会话）
  - 窗格结构统一：**标题栏（会话名 + 状态徽标 + ×）+ 中间区 + 底部简化输入条**；新对话格中间为居中轻提示（无大标题/居中卡片）
  - **底部输入条极简三件套**：`[＋] [单行输入] [↑ 发送]`——原工具栏功能全收进 **＋ 菜单**（向上弹出）：插入（添加附件 / 引用·@长录音，长录音复用 fixed 录音小窗，加入输入框后输入条上方显示附件行）+ 设置（编辑模式/运行模式/模型/上下文，点击内联展开二级选择，右侧显示当前值）；有内容时发送 btn 点亮，Enter 直发
  - **空窗格**：「＋ 打开会话」→ 窗格内会话选择浮层（搜索 + 空白新对话 + 历史会话列表带 Gate/运行中/手动徽标；已在其他窗格打开的置灰）；选中装入该格并出现输入条；未分配窗格不显示输入条
  - **滚动加载更多窗格**：**每屏固定 4 格占满视口**（行高 = 视口半高，container query）；网格内容底部常驻「**⌄ 滚动继续加载更多窗口**」条——**滚到底自动新增一排 2 格**（IntersectionObserver，600ms 节流）/ **点击立即新增**，无限增加；已有窗格会话分配不动；关闭多视窗重开重置回初始 2×2
  - 窗格「×」= 该格置回未分配占位（不关整个多视窗）；消息流为静态 Mock（不接自动化引擎）
- 输入卡片工具栏：+ / @ </> 图标、绿色"自动接受编辑"下拉、"默认模式"下拉、"翼构 · 研发工程师 · qwen3.8-max"模型选择器、圆形发送按钮（空内容禁用态）
- **@ 引用菜单 + 长录音**：@ 按钮（录音中红色激活态）弹菜单含「长录音」——开启 **fixed 录音小窗**（默认锚定主区右上角 top:60/right:24，**头部可拖动**，越界钳制）：红呼吸圆点 + mm:ss 计时 + 音柱动效 + 转写区**只展示最近一句**（每 3s 换句淡入替换）；「停止」→ **已停止态（小窗不关）**：文件行「🎙 录音.mp3 · mm:ss」+ 定格转写 + 三操作——红「继续」（同段录音恢复计时，不归零）/ 绿「加入输入框」（把 **录音.mp3 附件条** 放进输入卡片 textarea 上方：icon + 文件名 + 时长 + Mock KB + × 移除；同 id 去重、新一轮替换）/ 灰禁用「详情」（占位，录音详情页后续接入）+ 头部「×」关闭丢弃
- 上下文选择器：📁 loomweb ⌄ · ⎇ dev ⌄

    - 审查标准（审查规则）：五分类（正确性/可维护性/性能/测试/规范）× 检查项；预置 10 条最佳实践（含**坏例 ⇄ 好例 mono 对比**，仅可启停）+ 自定义增删改启停（FormModal：标题/分类/级别倾向/说明/坏例/好例/适用范围，同分类重名拦截）；每条审查意见强制挂载检查项
    - 一致性报告（质量检验）：KPI 4 枚（整体一致率 / ADE 误报率 / ADE 漏检 / 已完成审查，从已完成 MR 的裁决结果实时聚合，阈值着色）+ 漏检清单（MR 引用 + 检查项引用 + **[强化该检查项]** 反哺弹窗，预填分类与说明）+ 薄弱检查项（按检查项归因一致/漏检/误报，风险徽标重点强化/需关注/健康）
  - 安全审查：顶部**扫描/阻断策略紧凑条**（一行三格：MR 阻断开关 / 自动创建 Issue 开关 / 扫描范围下拉 全量·增量·全量+增量，切段不隐藏；三个策略名各带问号图标，hover/focus 显示解释说明浮层）+ 分段「审查规则 / 审查记录」——规则段：**预设安全规则 10 条**（硬编码密钥/SQL注入/XSS/反序列化/弱加密/敏感日志/CORS/路径遍历/漏洞依赖/调试残留，默认启用，仅可启停，行展开看匹配方式/规则内容/适用范围）+ **自定义规则**（新建/编辑弹窗：规则名/严重级别/匹配方式 关键词|正则/规则内容（正则合法性校验）/适用范围/说明；启停/编辑/移除）；记录段：**立即审查**（1.2s 模拟执行 → 记录置顶自动展开，结果与启用规则强联动）+ 记录行（时间/触发徽标/范围 + 应用规则数与问题统计）+ 展开问题明细（严重度徽标/规则名/文件:行号 mono/描述/建议/代码片段，**标记已修复/忽略**状态流转，计数联动）
  - 占位：测试（敬请期待面板）
  - 所有新增类操作（新建文档/导入文档/添加成员/申请专属ADE/添加记忆/新建任务）统一使用居中弹窗（FormModal）

## 交互

- Home/Code 分段切换
- 各下拉菜单可展开选择（编辑模式 / 运行模式 / 模型 / 项目 / 分支）
- 输入框可输入，有内容时发送按钮变为可用态，Enter 发送
- 标题栏侧边栏图标可收起/展开侧边栏
- **侧边栏「新对话」**：从项目中心/详情页一键回首页会话框（home 视图，菜单项选中态联动）
- **@ →「长录音」**：右上角录音小窗（可拖动）→ 停止/继续计时 → 加入输入框（录音.mp3 附件条）/ 关闭
- **首页多视窗**：右上角 btn 切 2×2 四窗格 → 空窗格「＋ 打开会话」弹选择浮层装入历史会话 → 输入条「＋」弹功能菜单（二级选择切换设置）→ 窗格「×」置回未分配 → 再点 btn 恢复单窗口
- 项目中心：卡片点击进详情、导航切换、规范文档搜索/预览/编辑保存、知识文档二级页面预览/编辑、自动化任务启停
