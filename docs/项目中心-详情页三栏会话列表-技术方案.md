# 「详情页三栏布局：历史会话常驻左栏」技术方案

> 创建日期：2026-10-22
> 更新日期：2026-10-22

> **⚠️ 本方案未实施即被替代**：需求升级为四格布局（+ Terminal 工具日志格），见 `项目中心-详情页四格布局-技术方案.md`。

## 0. 需求（鹿鹿子大王）

项目中心详情页由「左会话区 + 右配置 tab」双栏改为**左中右三栏**：

- **最左**：历史会话列表**常驻展示**（替代原 🕘 icon 点击打开的左滑覆盖式抽屉）；
- **中间**：当前会话详情（消息流 + 插话输入）；
- **右侧**：项目配置 tab（不动）。

## 1. 现状与问题

| # | 现状 | 问题 |
|---|---|---|
| 1 | 历史会话藏在 🕘 icon 的覆盖式抽屉里 | 会话列表不可见，切换会话需两步（点 icon → 点条目），未读状态被动 |
| 2 | 抽屉 276px + 遮罩，与成员抽屉互斥 | 覆盖消息流，无法「看着列表读消息」 |

## 2. 方案总览（结构）

```
detail-inner（横向 flex）
├── chat-pane（原 34% → 50% / min 560px，内部改为横向 flex）
│   ├── session-rail   ★新：常驻历史会话列表（204px，flex-shrink 0，浅灰底）
│   │   ├── rail-head      「历史会话 · N 个」
│   │   ├── rail-body      会话条目（名称+未读 / 状态徽标+来源副文案），当前高亮
│   │   └── rail-foot      ＋ 新对话 + 提示文案
│   └── chat-main      中栏主体（flex 1 / min-width 0，纵向 flex = 原 chat-pane 全部内容）
│       ├── chat-head        返回 / 项目名 / 状态 / 编辑（不动）
│       ├── chat-session-bar 当前会话行 + 👥 成员 icon（🕘 历史 icon 删除）
│       ├── chat-stream      消息流（不动）
│       ├── chat-input       插话输入（不动）
│       └── MembersDrawer    成员抽屉仍为覆盖式（挂 chat-main 内）
└── detail-config（右栏：ClosableTabs + 面板，完全不动）
```

**关键决策**：

1. **不把会话状态上提到 ProjectDetail**——SessionRail 作为 ChatPane 内部子组件渲染，`activeSessionId / selectSession / handleNewSession` 全部留在 ChatPane，ProjectDetail 骨架零改动（`sessionFocus`、`focusJobId`、`onUpdateProject` 联动链路不变）；
2. **成员抽屉保持覆盖式**（本需求只涉及历史会话）；因 `.chat-drawer-*` 公共样式原定义在 HistoryDrawer.css，随文件删除**迁入 MembersDrawer.css**；
3. **HistoryDrawer.tsx/.css 删除**，由新组件 `SessionRail.tsx/.css` 承接（去遮罩/去关闭按钮/改常驻文档流布局，条目样式重写为 `.rail-*`）。

## 3. 宽度分配（窗口 1280 − 侧边栏 258 ≈ 主区 1022px）

| 区域 | 宽度 | 说明 |
|---|---|---|
| session-rail | 204px 固定 | 条目单行截断（省略号），204px 可容纳「名称 + 未读徽标」一行 +「状态徽标 + 来源」副行 |
| chat-main | flex:1（≈356px） | 与原 ChatPane 主体（min 360）基本持平，消息流不缩水 |
| chat-pane 整体 | `width: 50%; min-width: 560px`（flex-shrink 0） | 主区 1022 时实际 560；更宽视口按 50% 弹性增长 |
| detail-config | flex:1（≈462px） | 由原 ≈660 收窄；ClosableTabs 自带横向滚动，面板 `max-width: 720px` 仅是上限不受影响 |

窄视口降级：chat-pane 有 min-width 560 保护，右栏被压缩时面板内部滚动兜底（与原 34%/min360 行为同构）。

## 4. 组件设计

### 4.1 `SessionRail.tsx`（新，替代 HistoryDrawer）

```tsx
interface SessionRailProps {
  project: Project
  sessions: ProjectSession[]
  activeSessionId: string | null
  onSelect: (sessionId: string) => void
  onNewSession: () => void
}
```

- 常驻文档流（无 absolute / 无遮罩 / 无关闭按钮 / 无开关动画）；
- `rail-head`：`历史会话` + `N 个会话`；未读总数 > 0 时显示总数徽标（承接原 🕘 icon 角标语义）；
- 条目两行结构（204px 窄列适配，较原抽屉去 ChatIcon）：
  - 第一行：会话名（ellipsis，flex:1）+ 未读小徽标；
  - 第二行：运行状态徽标（auto → `job.currentRun ?? history[0]` 状态映射，manual → `已结束`）+ `originText`（ellipsis）；
  - 当前会话高亮底色；点击 `onSelect`（清未读 + 切会话）；
- `rail-foot`：`＋ 新对话`（虚线框按钮，同原抽屉）+ 提示文案「任务的每个阶段 = 独立会话…」；
- 排序：`order` 降序（同原抽屉）。

### 4.2 `ChatPane.tsx`（改）

- `drawer` 状态收敛为 `boolean`（成员抽屉开关；`'history'` 分支删除）；
- 渲染结构改为 `chat-pane（row）→ SessionRail + chat-main（column）`；原 JSX（head/session-bar/stream/input/MembersDrawer）整体包进 `chat-main`；
- `chat-session-bar` 中 🕘 历史会话 icon 按钮与 `unreadTotal` 角标删除（未读展示职责移交 rail）；👥 成员 icon 保留；
- 空态文案改为「暂无会话，点击左侧「＋ 新对话」新建」；
- `selectSession` / `handleNewSession` 中 `setDrawer(null)` 保留（点会话时收起成员抽屉）。

### 4.3 `ChatPane.css`（改）

- `.chat-pane`：`flex-direction: row`；`width: 34% → 50%`、`min-width: 360px → 560px`；背景 `#fcfcfd` 移至 `.chat-main`；
- 新增 `.chat-main`：`flex: 1; min-width: 0; display: flex; flex-direction: column; position: relative（成员抽屉定位基准）; background: #fcfcfd`；
- 删除 `.icon-badge`（历史 icon 专用角标）；`.icon-toggle` 保留（成员 icon 使用）；
- 「抽屉定位基准」注释从 .chat-pane 移至 .chat-main。

### 4.4 `MembersDrawer.css`（改）

- 头部迁入 `.chat-drawer-mask / .chat-drawer / .chat-drawer-head / -title / -count / -add / -close / -body / -foot` 公共样式（自 HistoryDrawer.css 原样搬迁，仅删与抽屉互斥注释中「历史会话」字样）；
- 成员抽屉宽度 276px 不变，在 chat-main（≈356px）内覆盖显示，行为不变。

### 4.5 删除文件

- `HistoryDrawer.tsx` / `HistoryDrawer.css`（功能由 SessionRail + MembersDrawer.css 承接）。

## 5. 交互细节

| 场景 | 行为 |
|---|---|
| 进入详情页 | 左 rail 常驻显示全部会话（order 降序），当前会话（默认 order 最大）高亮；中栏显示其消息流 |
| 点 rail 条目 | 切会话 + 清未读 + 消息流切换（auto 会话实时联动引擎不变）；成员抽屉若开着则收起 |
| rail 未读展示 | 每条目未读小徽标 + 头部总数徽标（原 🕘 icon 角标语义） |
| ＋ 新对话 | 新建 manual 会话置顶并切为当前（置顶 = order 最大，rail 中自然排首位） |
| 通知跳转 / 工作流「在左栏打开本步骤会话」 | `focusJobId` / `sessionFocus` → `selectSession` 链路不变，目标会话在 rail 中高亮可见 |
| 成员抽屉 | 中栏内覆盖式打开（👥 icon），互斥逻辑只剩自身开关 |
| 消息流吸底 / 插话 / Gate 按钮 | 不变（chat-main 内布局与原 chat-pane 完全同构） |

## 7. 实施顺序

1. 新增 SessionRail（组件 + 样式），ChatPane 接入三栏结构（build 绿）；
2. 删历史 icon / drawer 'history' 分支 / .icon-badge，空态文案更新；
3. 公共抽屉样式迁 MembersDrawer.css，删除 HistoryDrawer 两文件；
4. `tsc --noEmit` + `npm run build` + Playwright 视觉回归（三栏渲染/切换/未读/成员抽屉/通知跳转）；
5. README 更新 + commit。

## 8. 验证点

1. 详情页三栏渲染：左 rail 5 条会话（当前「每日构建」高亮）、中栏消息流、右栏 tab 不变；
2. rail 条目：名称截断省略号、状态徽标（运行中/等待确认/已结束）、未读徽标（s2、s3 各 1）+ 头部总数 2；
3. 点「周报生成 · 发布确认」→ 中栏切 Gate 会话、未读清零、批准/拒绝与右栏待处理卡片联动；
4. ＋ 新对话 → rail 置顶新条目并切为当前，输入框即刻可插话（人消息 + 1.5s ADE 回应）；
5. 👥 成员抽屉：中栏内覆盖打开/关闭、添加/行内编辑/移除回归；
6. 通知跳转：点周报通知 → 右栏 automation tab 激活 + 待处理卡片高亮 + rail 中目标会话高亮切换；
7. 窄视口（窗口缩放）：rail 204 固定、chat-main 不塌陷（min-width 保护）；
8. `npm run build` 通过。
