# 「项目中心 - 安全审查」策略说明问号图标 - 技术方案

> 创建日期：2026-09-03
> 更新日期：2026-09-03（实施修正：`.policy-name` 自带 `overflow: hidden`（文字省略号）会裁掉其内部浮层——改为新增 `policy-label` 外层（不设 overflow）包裹名称 + 问号，浮层移出裁切祖先；DOM 结构与 3.4 节同步更新）

## 1. 背景与目标

项目中心「安全审查」tab 顶部为扫描/阻断策略紧凑条（一行三格）：

1. **MR 阻断**（Toggle）
2. **自动创建 Issue**（Toggle）
3. **扫描范围**（下拉：全量 / 增量 / 全量+增量）

三个策略格目前仅有原生 `title` 悬停提示（浏览器延迟约 1s、样式不可控、触屏无效），用户难以理解各策略的含义与影响。

**本次需求**：在三个策略小标题（`MR 阻断` / `自动创建 Issue` / `扫描范围`）后各加一个**问号图标**，hover 时以自定义浮层展示该策略的解释说明。

## 2. 现状分析

| 项 | 现状 |
|---|---|
| 策略条结构 | `SecurityPanel.tsx` ① `policy-bar` → 三个 `policy-cell`（`policy-name` + Toggle / select） |
| 现有提示 | 每格 `title` 原生提示，文案已定（见 `SecurityPanel.tsx` 189-209 行） |
| 图标库 | `src/components/icons/index.tsx` 内联 SVG 线框图标（`base()` 工厂），**无问号图标** |
| 浮层组件 | 工程内**无通用 Tooltip**；相关形态参考：`Dropdown.tsx`（绝对定位菜单）、`RunModal` 内浮层、`StatusBadge`（徽标） |
| 样式体系 | CSS 变量 `--main-bg / --border / --row-divider / --text-primary / --text-secondary`；卡片圆角 9-10px、边框 1px、字号 11.5-12.5px |

**结论**：需新增 ① `HelpIcon`（问号线框图标）② 轻量 hover 浮层（纯 CSS 或小组件）。遵循工程「无第三方依赖、组件级 CSS」约束，不引入浮层库。

## 3. 方案设计

### 3.1 图标（`src/components/icons/index.tsx`）

新增 `HelpIcon`——圆圈 + 问号路径，与既有线框风格一致（stroke 1.5、圆头）：

```tsx
/** 问号（帮助说明） */
export const HelpIcon = (p: IconProps) =>
  base(p, (
    <>
      <circle cx="12" cy="12" r="8.5" />
      <path d="M9.5 9.3a2.5 2.5 0 0 1 4.9.6c0 1.7-2.4 2.1-2.4 3.6" />
      <circle cx="12" cy="17" r="0.2" fill="currentColor" stroke="none" />
    </>
  ))
```

### 3.2 说明浮层（纯 CSS hover，不引入 state）

策略格较窄，浮层文案较长，采用 **CSS hover + 绝对定位浮层**，挂在 `policy-cell` 内：

- 结构：`policy-name` 后加 `<span class="policy-help">`（内含 `HelpIcon` + `policy-help-tip` 浮层 div）；
- 触发：`.policy-help:hover .policy-help-tip` / `:focus-visible` 显示（0.12s 淡入）；
- 定位：`position: absolute; top: calc(100% + 6px); left: 0`，宽度 220px（`扫描范围` 格因右侧有 select，浮层左对齐避免溢出）；`.policy-bar` 设 `position: relative` 无需——浮层相对 `policy-help` 定位即可，但需保证父级无 `overflow: hidden`。**注意**：`.policy-bar` 现有 `overflow: hidden`（圆角裁切），会把浮层裁掉，需把 `overflow: hidden` 换成给三格 `border-radius` 处理——改用「首格左圆角、末格右圆角」方案：`.policy-cell:first-child { border-radius: 10px 0 0 10px }`，`.policy-cell:last-child { border-radius: 0 10px 10px 0 }`，`.policy-bar` 去掉 `overflow: hidden`；
- 兜底：浮层 `z-index: 30`（高于行内容与徽标，低于弹窗 100）。

### 3.3 文案（复用现有 title 语义，略作展开）

| 策略 | 浮层文案 |
|---|---|
| MR 阻断 | 开启后，审查发现高危问题时将阻断合并请求（MR），问题修复或确认忽略后方可合并 |
| 自动创建 Issue | 开启后，发现高危问题时自动在 GitLab 创建对应 Issue，指派给问题引入者跟进修复 |
| 扫描范围 | 全量：每日对整个仓库扫描一遍；增量：仅扫描 MR 变更文件；全量+增量：两者结合，覆盖最全 |

### 3.4 结构改动（`SecurityPanel.tsx`）

```tsx
<div className="policy-cell">
  <span className="policy-label">
    <span className="policy-name">MR 阻断</span>
    <span className="policy-help" tabIndex={0} role="note">
      <HelpIcon size={13} />
      <span className="policy-help-tip">开启后，审查发现高危问题时将阻断合并请求（MR）…</span>
    </span>
  </span>
  <Toggle … />
</div>
```

> **实施修正**：最初把问号放在 `policy-name` 内部，但 `.policy-name` 有 `overflow: hidden`（文字省略号必需），会把 hover 浮层裁掉（表现为浮层不可见/只露一半）。因此新增 `.policy-label` 外层（`inline-flex`，不设 overflow）同时容纳名称与问号，浮层不在任何裁切祖先内。

- 每格的 `title` 原生提示**删除**（被浮层替代，避免双提示）；
- `policy-help` 内 `HelpIcon` 默认灰色（`--text-secondary`），hover 变主文字色；
- 浮层内文案 11.5px、`line-height 1.5`、左对齐、支持换行。

### 3.5 样式改动（`SecurityPanel.css`）

```css
.policy-bar { /* 去掉 overflow: hidden */ }

.policy-cell:first-child { border-radius: 10px 0 0 10px; }
.policy-cell:last-child { border-radius: 0 10px 10px 0; }

.policy-name { display: inline-flex; align-items: center; gap: 5px; }

.policy-help {
  position: relative;
  display: inline-flex;
  color: var(--text-secondary);
  cursor: help;
  flex-shrink: 0;
}

.policy-help-tip {
  display: none;
  position: absolute;
  top: calc(100% + 7px);
  left: 0;
  width: 220px;
  padding: 8px 10px;
  background: var(--text-primary);  /* 深底浅字，区别于卡片，常见 tooltip 形态 */
  color: #fff;
  font-size: 11.5px;
  line-height: 1.5;
  text-align: left;
  border-radius: 8px;
  z-index: 30;
  white-space: normal;
}

.policy-help:hover .policy-help-tip,
.policy-help:focus-visible .policy-help-tip { display: block; }
```

### 3.6 边界与细节

1. **切换段不隐藏**：策略条在面板顶部，切段不影响，浮层逻辑无涉；
2. **面板滚动容器**：浮层随内容滚动自然移动（绝对定位于 `policy-help`），不做 fixed 跟随；鼠标移开即隐藏，无遮挡列表风险；
3. **触屏**：`tabIndex={0}` + `:focus-visible` 支持点按聚焦显示（键盘 Tab 也可达）；
4. **第三格浮层右溢出**：左对齐 + 220px 宽，最右侧 `扫描范围` 格 `left: 0` 起点靠左，实测面板宽度（约 760px+）不会溢出；若窗口极窄，浮层超出被外层裁切——Mock 演示可接受，不额外做翻转逻辑。
