# 「新建项目」功能 - 技术方案

> 创建日期：2026-08-28
> 更新日期：2026-08-28

## 1. 背景与目标

项目中心目前只有展示（卡片列表 + 详情页），**没有新建项目入口**。需求：

1. 项目中心列表页提供 **「+ 新建项目」** 入口；
2. 弹窗表单填写项目基本信息，创建后出现在列表中，可正常进入详情页；
3. 交互与视觉完全复用现有体系（FormModal 弹窗、Settings 式面板、text-btn 按钮）。

本工程为纯前端 Mock，新建仅写入本地 state（刷新即恢复），与成员/记忆等现有写操作一致。

## 2. 现状分析

| 项 | 现状 |
|---|---|
| 数据流 | `App.tsx` 持有 `projects` state（初始为 Mock `initialProjects`），各面板写操作走 `handleUpdateProject(id, updater)`；**没有新增项目的通道** |
| 列表页 | `ProjectCenter.tsx`：标题 + 副标题（共 N 个项目）+ 卡片网格，无任何操作按钮 |
| 弹窗 | `FormModal`（遮罩 + 居中 + 标题栏 + 字段 + 取消/确认）已被新建索引/导入/添加成员/添加记忆等复用 |
| 字段 | `Project` 必填字段较多：`members / agents / autoJobs / knowledge / specs` 均为嵌套结构，新建时需给空默认值 |
| 周期 | 上一期刚加的 `startDate / endDate`，新建表单应一并录入 |

## 3. 总体设计

### 3.1 数据层（`src/data/projects.ts`）

新增工厂函数，集中空结构默认值，避免组件里手写大对象：

```ts
export function createEmptyProject(input: {
  name: string
  description: string
  status: Project['status']
  startDate: string
  endDate: string
}): Project
```

- `id`：`p${Date.now()}`；
- `createdAt`：当天 `YYYY-MM-DD`；
- `members / agents / autoJobs / specs`：空数组；
- `knowledge`：空 folders/docs/memories + 默认 memorySettings（autoCollect 关、collectRules 空、retentionDays 90、permanent false、expirePolicy 自动归档）。

### 3.2 列表页（`ProjectCenter.tsx` + css）

- 副标题行右侧加「+ 新建项目」`text-btn`（与详情页各面板的「+ 新建索引」「+ 添加」同款）；
- 布局：标题行改为 flex（标题/副标题左，按钮右），按钮垂直对齐标题基线；
- 点击打开 FormModal。

### 3.3 新建弹窗（复用 FormModal）

字段（全部必填，日期用原生 `<input type="date">`）：

| 字段 | 控件 | 默认值 | 校验 |
|---|---|---|---|
| 项目名 | input | 空 | 非空；且不与现有项目名重复（重复时确认按钮禁用 + 行内提示） |
| 简介 | input | 空 | 非空 |
| 状态 | select | 规划中 | — |
| 开始日期 | date | 空 | 非空 |
| 截止日期 | date | 空 | 非空且 ≥ 开始日期（否则确认禁用 + 提示） |

- 确认按钮 disabled 条件：任一校验不过；
- 确认后：`onCreateProject(project)` → App 层 `setProjects([p, ...list])`，关闭弹窗并清空表单；
- 新项目卡片立即出现在网格首位（周期徽标按上一期 `getPeriodState` 规则自然呈现，如「N 天后启动」）。

### 3.4 App 层（`App.tsx`）

- `ProjectCenter` 新增 prop `onCreateProject: (p: Project) => void`；
- App 实现：`setProjects((list) => [p, ...list])`（新项目置顶）。

## 4. 改动文件清单

| 文件 | 改动 |
|---|---|
| `src/data/projects.ts` | 新增 `createEmptyProject()` 工厂 |
| `src/components/ProjectCenter.tsx` | 标题行加「+ 新建项目」按钮 + FormModal 表单（含校验） |
| `src/components/ProjectCenter.css` | 标题行 flex 布局 + 按钮对齐样式 |
| `docs/项目中心-技术方案.md` | 同步更新（更新日期 + 新建入口说明） |

## 5. 验证方式

1. `npx tsc --noEmit` + `npm run build` 通过；
2. 页面自查：
   - 点「+ 新建项目」弹窗打开，空表单时确认禁用；
   - 截止日期早于开始日期时确认禁用并提示；
   - 项目名与现有重复时确认禁用并提示；
   - 创建成功后卡片出现在网格首位，副标题计数 +1，可进入详情页（各面板为空态）；
3. 提交 commit：`feat: 项目中心支持新建项目（弹窗表单 + 空项目默认结构）`。

## 6. 边界与取舍

- **不做编辑/删除项目**：本期只补新建；编辑（改名/改周期/改状态）与删除项目涉及确认交互，待有诉求再做；
- **不做持久化**：与现有写操作一致，刷新恢复 Mock 数据；
- **成员/ADE 不在新建表单**：新建后进详情页的「项目成员」「项目ADE」面板里添加，避免弹窗过长。
