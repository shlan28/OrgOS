# 「团队知识库」目录树支持多层级 - 技术方案

> 创建日期：2026-08-28
> 更新日期：2026-08-28

## 1. 背景与目标

「项目中心 → 知识记忆 → 团队知识库」左侧目录树当前为**单层平铺**结构（`KbFolder { id, name }`，无层级字段，`folders.map()` 渲染一层）。

本次需求：目录树支持**多层级嵌套**——目录下可再建子目录，树形展示、可折叠展开，文档过滤与统计随层级联动。

## 2. 交互设计

### 2.1 树形展示与折叠

```
目录                    [+ 新建目录]
📄 全部文档 (3)
▾ 📁 架构 (2)         ⋯
    📄（缩进）▾ 📁 组件设计 (1)  ⋯
▸ 📁 接口 (1)         ⋯
```

- **缩进**：每层缩进 14px（根目录 8px 基础内边距）；
- **折叠箭头**：有子目录的目录行左侧显示 ▸/▾ 小箭头（12px，点击切换折叠/展开，不影响选中）；无子目录的目录行显示等宽占位符保持对齐；
- **默认状态**：全部展开；
- **数量徽标**：目录行的 (N) 统计**该目录及全部子孙目录**下的文档总数（如「架构 (2)」= 自身 1 篇 + 子目录 1 篇）。

### 2.2 选中过滤（含子孙）

- 点击目录名 → 右栏显示**该目录及全部子孙目录**下的文档（与数量徽标口径一致）；
- 分组标题显示目录**完整路径**：如「架构 / 组件设计（1 篇）」；「全部文档」不变。

### 2.3 新建目录（弹窗增加上级目录）

「+ 新建目录」弹窗增加「上级目录」下拉：

```
┌ 新建目录 ──────────────┐
│ 目录名   [          ]  │
│ 上级目录  [无（根目录）⌄] │
│           ├ 无（根目录） │
│           ├ 架构        │
│           ├ 架构 / 组件设计│
│           └ 接口        │
│         [取消] [创建]    │
└────────────────────────┘
```

- 上级目录选项 = 「无（根目录）」+ 所有已有目录（以路径展示），默认「无（根目录）」；
- 创建后选中新目录。

### 2.4 重命名 / 删除

- **重命名**：不变（弹窗改目录名）；
- **删除**：禁用条件扩展——目录下**有文档或有子目录**时均不可删除，提示「请先移出或删除目录下的文档与子目录」；删除确认弹窗文案不变；
- 删除后若当前选中目录在被删目录的子树内 → 回退到「全部文档」。

### 2.5 导入弹窗的所属目录

「所属目录」下拉选项以**路径**展示（如「架构 / 组件设计」），避免同名目录混淆。

## 3. 数据模型改动（`src/data/projects.ts`）

```ts
/** 知识库目录（用户创建管理，支持多层级） */
export interface KbFolder {
  id: string
  name: string
  /** 父目录 id，空 = 根目录 */
  parentId?: string
}
```

**Mock 数据**（loomweb 演示嵌套，yigou-app 保持单层验证兼容）：

- loomweb：`架构`（根）→ 子目录 `组件设计`；`接口`（根）；「模块分布说明」移入 `组件设计`，「Loom 架构设计说明」留 `架构`，「接口约定 v2」留 `接口`；
- yigou-app：`支付`（根）不变。

## 4. 组件改动（`KnowledgePanel.tsx`）

### 4.1 新增/调整的派生逻辑

```ts
/** 目录的子孙 id 集合（含自身） */
const subtreeIds = (folderId: string): Set<string>
/** 目录路径文案：架构 / 组件设计 */
const folderPathLabel = (folderId: string): string
/** 目录下的文档数（含子孙目录） */
const countIn = (folderId: string): number   // 改为含子孙
/** 选中目录的可见文档 */
const visibleDocs = ...                       // 改为 folderId ∈ subtreeIds(selectedFolder)
```

### 4.2 状态

- 新增 `collapsedIds: string[]`（折叠的目录 id 集合，默认空 = 全展开）；
- `newFolderParent: string`（新建目录弹窗的上级目录，默认 `''` = 根）。

### 4.3 树渲染改为递归

```tsx
const renderFolderNode = (folder: KbFolder, depth: number) => (
  <div key={folder.id}>
    <div className="kb-tree-node">
      <button className="kb-tree-item" style={{ paddingLeft: 8 + depth * 14 }}>
        {有子目录
          ? <折叠箭头 onClick={切换折叠} />
          : <span className="kb-tree-toggle-spacer" />}
        <FolderIcon /> <名称 /> <数量 /> <⋯菜单 />
      </button>
      {⋯菜单（重命名/删除，删除禁用条件扩展）}
    </div>
    {!折叠 && 子目录.map(c => renderFolderNode(c, depth + 1))}
  </div>
)
```

### 4.4 弹窗调整

- 「新建目录」弹窗：增加「上级目录」下拉（无（根目录）+ 各目录路径）；
- 「导入文档」弹窗：所属目录选项改用路径文案；
- 「删除目录」确认弹窗：文案不变，删除 handler 增加子树选中回退判断。

## 5. 样式改动（`KnowledgePanel.css`）

```css
/* 折叠箭头按钮（12px，独立点击区域） */
.kb-tree-toggle { width: 14px; height: 14px; ... }
.kb-tree-toggle svg { transition: transform 0.15s ease; }
.kb-tree-toggle.open svg { transform: rotate(90deg); }  /* ▸ → ▾ */

/* 无子目录时的对齐占位 */
.kb-tree-toggle-spacer { width: 14px; flex-shrink: 0; }
```

缩进用内联 `paddingLeft` 实现，不新增 class。

## 6. 实施步骤

1. `projects.ts`：`KbFolder` 增加 `parentId`；loomweb Mock 数据改为嵌套结构；
2. `KnowledgePanel.tsx`：派生逻辑（subtreeIds / folderPathLabel / countIn 含子孙 / visibleDocs 含子孙）+ 折叠状态 + 递归树渲染 + 弹窗调整（新建目录上级下拉、导入路径选项、删除子树回退）；
3. `KnowledgePanel.css`：折叠箭头与占位样式；
4. `README.md` 更新描述；
5. `npm run build` 验证；
6. 浏览器自检：嵌套展示、缩进、折叠/展开、选中过滤含子孙、数量统计、新建子目录、重命名、删除禁用条件、导入路径选项；
7. 提交 git commit。

## 7. 验收标准

1. 目录树按 `parentId` 递归渲染，子目录缩进一级，层级不限；
2. 有子目录的行带 ▸/▾ 折叠箭头（点击只折叠不切换选中），无子目录的行对齐不塌陷；
3. 目录数量徽标 = 自身 + 子孙目录文档总数；点击目录右栏过滤口径一致；分组标题显示完整路径；
4. 「+ 新建目录」弹窗可选上级目录（默认根），可创建嵌套目录并自动选中；
5. 目录下有文档**或子目录**时删除禁用并提示；删除后选中目录若在子树内回退「全部文档」；
6. 导入弹窗所属目录以路径展示；
7. yigou-app 单层目录行为不回归；
8. 构建通过，代码提交 commit。

## 8. 风险与说明

- 纯 Mock 改动；`parentId` 形成环（A 的父是 B、B 的父是 A）时递归会死循环——Mock 数据受控不构造环，代码不做防御（保持简单，后续接后端时由接口保证）；
- 折叠状态为组件本地 state，切换「团队知识库 / 记忆」分段后重置为全展开（可接受）。
