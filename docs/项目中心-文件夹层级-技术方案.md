# 「项目中心 · 文件夹层级」功能 - 技术方案（方案 C：文件夹卡片 + 面包屑下钻）

> 创建日期：2026-08-28
> 更新日期：2026-08-28（实现完成：9/9 自测场景通过，FormModal 补充 Escape 关闭）

## 1. 背景与目标

项目中心列表页目前为**单层卡片网格**，所有项目平铺展示。随着项目数量增长，需要增加一个**文件夹层级**，每个项目可被放进一个文件夹中。

选定 **方案 C（Finder 式）**：

1. 顶层视图：文件夹渲染为**特殊卡片**（堆叠图标 + 名称 + 项目数），未分组项目直接平铺；
2. 点击文件夹卡片**下钻**进入文件夹内部视图，顶部**面包屑**「项目中心 › 文件夹名」可返回；
3. 顶层标题行新增「**＋ 新建文件夹**」按钮（弹窗输入名称）；
4. **新建项目弹窗新增「所属文件夹」下拉**：可选择已有文件夹或「不放入文件夹」；在文件夹内部视图触发新建时，默认选中当前文件夹。

示意图：`../docs/项目中心-文件夹层级-方案示意图.html`（方案 C 区块 ①②③）。

## 2. 现状分析

| 项 | 现状 |
|---|---|
| 数据模型 | `Project`（`src/data/projects.ts`）无归属字段；Mock 项目 3 个：loomweb / yigou-app / data-pipeline |
| 列表页 | `ProjectCenter.tsx`：标题行（标题 + 统计 + 「＋ 新建项目」）+ `project-grid` 卡片网格 |
| 新建项目 | `ProjectCenter.tsx` 内 `FormModal`：项目名/简介/状态/开始日期/截止日期，重名与日期倒序校验 |
| 视图状态机 | `App.tsx`：`View = home \| project-center \| project-detail`，`useState` 驱动，无路由库 |
| 卡片组件 | `ProjectCard.tsx`：文件夹图标 + 名称 + 状态徽标 + 简介 + 周期 + 成员概况 |

## 3. 数据模型设计

### 3.1 新增 `ProjectFolder` 类型（`src/data/projects.ts`）

```ts
/** 项目文件夹（单层，不嵌套） */
export interface ProjectFolder {
  id: string
  name: string
}

export const projectFolders: ProjectFolder[] = [
  { id: 'f-dev', name: '研发线' },
  { id: 'f-data', name: '数据平台' },
]
```

### 3.2 `Project` 增加归属字段

```ts
export interface Project {
  // ...现有字段不变
  /** 所属文件夹 id（空 = 未分组） */
  folderId?: string
}
```

### 3.3 Mock 数据调整

- `loomweb`、`yigou-app` → `folderId: 'f-dev'`（研发线）
- `data-pipeline` → `folderId: 'f-data'`（数据平台）
- `createEmptyProject` 入参增加 `folderId?: string`，写入新项目

### 3.4 状态提升

文件夹列表与项目列表同属项目中心域，**状态提升到 `App.tsx`**（与 `projects` 同级）：

```ts
const [folders, setFolders] = useState<ProjectFolder[]>(initialFolders)
```

`ProjectCenter` props 增加 `folders` / `onCreateFolder` / `onRenameFolder` / `onDeleteFolder`（见 5.2）。

## 4. 视图状态机扩展

`ProjectCenter` 内部增加**页内层级状态**（不改动 `App.tsx` 的 View 类型，下钻属于项目中心页内行为）：

```ts
/** 页内层级：null = 顶层；string = 当前文件夹 id */
const [openFolderId, setOpenFolderId] = useState<string | null>(null)
```

- 顶层：渲染文件夹卡片网格 + 未分组项目卡片网格；
- 下钻：渲染该文件夹内项目卡片 + 面包屑；
- 面包屑「项目中心」点击 → `setOpenFolderId(null)`；
- 从项目详情返回（`onBack`）时回到项目中心**顶层**（现状不变，`openFolderId` 因组件重挂载自然重置）。

## 5. 页面与交互设计

### 5.1 顶层视图

```
┌────────────────────────────────────────────────────────┐
│ 项目中心                          [＋ 新建文件夹] [＋ 新建项目] │
│ 共 3 个项目 · 2 个文件夹                                  │
│                                                        │
│ ┌──────────┐ ┌──────────┐ ┌──────────────┐             │
│ │ ▷ 堆叠图标 │ │ ▷ 堆叠图标 │ │ 📁 ade-platform │          │
│ │ 研发线     │ │ 数据平台   │ │ ●已完成 …      │            │
│ │ 2 个项目   │ │ 1 个项目   │ └──────────────┘             │
│ └──────────┘ └──────────┘                               │
└────────────────────────────────────────────────────────┘
```

- 标题行右侧**两个按钮**：「＋ 新建文件夹」（灰描边 ghost 样式）+「＋ 新建项目」（现有绿色样式）；
- 副标题统计：`共 N 个项目 · M 个文件夹`（无文件夹时只显示项目数）；
- 文件夹卡片：`grid` 同列宽，浅灰底（`--sidebar-bg`）区分于项目卡片白底；内容 = 堆叠文件夹图标（纯 CSS 双层错位）+ 文件夹名（14.5px 加粗）+ `N 个项目`（12px 灰）；hover 上浮同项目卡片；
- 文件夹卡片右上角 `⋯` 菜单：**重命名 / 删除**（删除时若文件夹内有项目，项目自动回到未分组，弹窗二次确认提示「文件夹内 N 个项目将移至未分组」）；
- 未分组项目直接排在文件夹卡片之后，同一网格。

### 5.2 新建文件夹弹窗（FormModal）

- 字段：文件夹名（必填，**重名校验**：与现有文件夹同名时禁用创建并提示「文件夹名已存在」）；
- 确认后 `onCreateFolder({ id: 'f' + Date.now(), name })`，插入 folders 列表尾部。

### 5.3 文件夹内部视图（下钻）

```
┌────────────────────────────────────────────────────────┐
│ 项目中心 › 研发线                                        │
│ 2 个项目                              [＋ 新建项目]      │
│                                                        │
│ ┌──────────────┐ ┌──────────────┐                      │
│ │ 📁 loomweb …  │ │ 📁 yigou-app… │                     │
│ └──────────────┘ └──────────────┘                      │
└────────────────────────────────────────────────────────┘
```

- 面包屑：`项目中心 › {文件夹名}`，「项目中心」为可点击返回项（灰色，hover 变深），当前层级加粗黑色；
- 面包屑行右侧保留「＋ 新建项目」按钮（**不显示**「新建文件夹」，文件夹内不能建文件夹——单层约束）；
- 副标题：`N 个项目`；
- 空文件夹：居中空状态（灰色文件夹图标 + 「该文件夹还没有项目」+ 12.5px 灰说明「新建项目时选择该文件夹，或从顶层拖入」——本期不做拖拽，文案只引导新建）。

### 5.4 新建项目弹窗（改造现有）

在「简介」与「状态」之间插入一个字段：

```
所属文件夹：[研发线 ▾]     ← select，选项 = 各文件夹 + 「不放入文件夹」
```

- **顶层触发**：默认选中「不放入文件夹」；
- **文件夹内部触发**：默认选中**当前文件夹**（选项文案标注「（当前）」）；
- 选项值：文件夹 id；「不放入文件夹」值为空字符串 → `folderId: undefined`；
- 其余字段与校验（重名/日期倒序）不变。

### 5.5 项目卡片「移动到文件夹」

项目卡片 hover 时右上角显示 `⋯` 菜单（替代/叠加现有布局，不与状态徽标冲突——徽标移到 ⋯ 左侧）：

- 菜单项：`移动到 ›`（子菜单列出各文件夹 + 「未分组」，当前所属项打勾）；
- 选择后 `onMoveProject(projectId, folderId | undefined)`，卡片即时更新归属；
- 在文件夹内部视图把项目移出后，若文件夹变空则停留在该文件夹视图（显示空状态）。

> 说明：卡片本身是 `<button>`，`⋯` 菜单需 `stopPropagation` 防止触发进详情。若实现复杂度超预期，可降级为「进详情页头部加归属行」——但优先做卡片 ⋯ 菜单，与示意图一致。

## 7. 边界与校验规则

| 场景 | 规则 |
|---|---|
| 文件夹重名 | 新建/重命名时与现有文件夹同名 → 禁用确认 + 红字提示 |
| 删除文件夹 | 有项目时弹窗二次确认，提示「N 个项目将移至未分组」；确认后项目 `folderId` 置空，文件夹移除 |
| 重命名文件夹 | 仅改 `folderId` 对应名称，项目归属不变 |
| 新建项目选文件夹 | 下拉必选其一（默认值见 5.4），无「空值非法」问题 |
| 下钻后删除当前文件夹 | ⋯ 菜单在内部视图也可用；删除后自动退回顶层 |
| 未分组项目 | `folderId` 为空的项目始终显示在顶层视图 |
| 单层约束 | 文件夹内不提供「新建文件夹」入口，数据结构也不支持嵌套 |

## 8. 验证要点（自测清单）

1. 顶层：文件夹卡片 + 未分组项目混排，统计正确；
2. 点击文件夹卡片 → 下钻，面包屑正确，返回正常；
3. 新建文件夹：重名拦截、创建后出现在顶层；
4. 新建项目：顶层触发默认「不放入文件夹」；文件夹内触发默认当前文件夹；创建后出现在对应位置；
5. 卡片 ⋯ 菜单移动项目：跨文件夹移动、移到未分组、移入后计数刷新；
6. 删除文件夹：有项目时二次确认 + 项目回未分组；空文件夹直接删；
7. 重命名文件夹：名称联动面包屑与卡片；
8. `npm run build` 通过（TypeScript 无错误）。
