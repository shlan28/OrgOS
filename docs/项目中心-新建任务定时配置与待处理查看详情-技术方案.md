## 1. 需求

1. **新建任务弹窗增加触发方式配置**：支持选择「定时 / 手动」；选「定时」时需支持选择**如何定时**（定时规则配置）；
2. **待人工处理卡片增加「查看详情」按钮**：点击打开该任务的运行弹窗（RunModal）。

## 2. 现状与差距

| 项 | 现状 | 目标 |
|---|---|---|
| 新建弹窗字段 | 任务名 / 工作流模板（2 项），触发方式固定默认值 `手动` | + 触发方式（定时/手动）；定时时展开定时规则配置 |
| 定时规则 | 无（`triggerParam` 为自由文本，如「每天 08:00」） | 结构化配置：频率（每天/每周/每月）+ 对应时间/星期/日期选择 |
| 待处理卡片操作 | 确认型：拒绝/批准；输入型：去填写 | 两类均增加「查看详情」按钮，打开 RunModal |

## 3. 设计

### 3.1 定时规则数据模型（`data/projects.ts`）

```ts
/** 定时规则（triggerType = '定时' 时使用） */
export interface ScheduleRule {
  /** 频率 */
  freq: '每天' | '每周' | '每月'
  /** 每天：HH:mm */
  time?: string
  /** 每周：星期几（1-7，1 = 周一） */
  weekday?: number
  /** 每月：几号（1-31） */
  day?: number
}

/** 定时规则 → 展示文案（任务行副标题 / RunModal 头部用） */
export function scheduleTextOf(rule: ScheduleRule): string {
  switch (rule.freq) {
    case '每天': return `每天 ${rule.time}`
    case '每周': return `每周${WEEKDAY_NAMES[rule.weekday]} ${rule.time}`
    case '每月': return `每月 ${rule.day} 日 ${rule.time}`
  }
}
```

`AutoJob` 增加可选字段 `schedule?: ScheduleRule`（`triggerType === '定时'` 时存在）。
`triggerParam` 保留为展示文案（由 `scheduleTextOf` 生成后写入），兼容现有渲染链路（任务行副标题、RunModal 头部、编辑模式）。

### 3.2 新建弹窗布局（`AutomationPanel.tsx`）

```
┌─ 新建任务 ────────────────────────────── × ┐
│  任务名                                    │
│  [ 如 每日构建 ______________________ ]    │
│                                            │
│  工作流模板                                │
│  [ 选择工作流模板 ▾________________ ]      │
│  ↗ 去 ADE Teams 页面编辑                  │
│                                            │
│  触发方式                                  │
│  (●) 定时   ( ) 手动        ← 单选组      │
│                                            │
│  ┌ 定时规则（仅定时时显示）─────────────┐  │
│  │ 频率  [ 每天 ▾ ]                    │  │
│  │ 时间  [ 08 ] : [ 00 ]               │  │
│  │ （每周时：星期 [ 周一 ▾ ]）          │  │
│  │ （每月时：日期 [ 1 ▾ ]）            │  │
│  └─────────────────────────────────────┘  │
│                        [取消]  [创建]      │
└────────────────────────────────────────────┘
```

- 触发方式：两个 radio（`定时` / `手动`），默认 `手动`；
- 选「定时」时展开规则区（缩进卡片式，浅灰底）：
  - **频率**：下拉（每天 / 每周 / 每月）；
  - **时间**：时（0-23）/ 分（0-59）两个下拉，默认 `08:00`；
  - **每周**：额外显示星期下拉（周一~周日，默认周一）；
  - **每月**：额外显示日期下拉（1-31，默认 1）；
- 「创建」禁用条件：任务名为空 或 未选模板（定时规则各字段有默认值，无需额外校验）；
- 创建时：`triggerType = '定时'` → `schedule` 写入 + `triggerParam = scheduleTextOf(schedule)`；`手动` → 沿用现状默认值。

### 3.3 待处理卡片「查看详情」（`GateCard.tsx`）

```
▎周报生成 · 运行 #r12                        [等待确认]
▎发布前确认
▎即将把周报发布到外部渠道，请确认内容无误。
▎(S) 需要你确认
▎运行至步骤 3/4 · 已等待 5 分钟   [查看详情] [拒绝] [批准]
```

- 位置：`gate-actions` 最左侧，`text-btn` 样式（次级操作，不与主操作竞争）；
- 确认型 / 输入型均显示；
- 点击 → `onOpenModal(job.id)`（复用现有回调，打开 RunModal）；
- 输入型原有「去填写 →」保留（主操作），「查看详情」在其左侧。

### 3.4 交互细节

- **RunModal 编辑模式**：本期不改（触发方式/参数仍为文本编辑，`schedule` 字段编辑暂不结构化——编辑保存时若改了 `triggerParam` 文本，展示以文本为准；后续需求再统一）；
- **通知跳转定位**：不受影响（落点仍是待处理卡片，不自动开弹窗）；
- 新建任务后任务行副标题显示 `模板名 · 定时 · 每天 08:00 · 尚未运行`。
