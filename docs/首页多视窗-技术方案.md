# 首页 · 多视窗（2×2 四窗格 + 每格底部简化输入条）

> 创建日期：2026-10-21
> 更新日期：2026-10-22（v2：每屏固定 4 格占满 + 底部常驻「滚动继续加载更多窗口」load-more 条，滚到底自动新增一排 2 格，可点击，无限增加；详见 §7）

## 1. 需求

1. **入口替换**：首页右上角现有 2 个 icon（`MonitorIcon` 预览 / `PanelRightIcon` 面板）移除，改为**一个「多视窗」btn**（田字格 icon）。
2. **切分四窗格**：点击 btn → 右侧主区切分为 **2×2 四窗格**，**当前会话（新对话）放进左上**；再次点击 btn → 恢复单窗口。btn 激活态高亮 + 角标显示当前窗格数。
3. **窗格结构统一**（v2 设计）：每格 = **标题栏（会话名 + 状态徽标 + ×）+ 消息流（/空态居中轻提示/未分配占位）+ 底部简化输入条**。**不再使用居中大标题 + 居中输入卡片**——左上「新对话」窗格中间为居中轻提示（气泡 icon +「发送消息，开始新对话」+ 上下文小字）。
4. **底部输入条极简**（v2 设计）：三件套 **`[＋] [单行输入] [↑ 发送]`**；原输入卡片工具栏全部功能（附件 / @ 长录音 / 编辑模式 / 运行模式 / 模型 / 上下文）**收进 ＋ 菜单**（菜单从输入条上方弹出，设置项右侧显示当前值，点开即二级选择切换）。
5. **空窗格**：「＋ 打开会话」→ 窗格内弹出**会话选择浮层**（搜索 + 空白新对话 + 历史会话列表，带 Gate/运行中/手动徽标），选中装入该窗格。未分配窗格**不显示输入条**。
6. **单窗口模式不变**：未切分时首页保持现状（大标题 + ChatInput 完整工具栏输入卡片 + ContextSelector）；多视窗仅在 home 视图可用。

## 3. 技术方案

### 3.1 状态机（App.tsx）

```ts
/** 首页多视窗窗格的会话槽位：'new' = 新对话；'history:<id>' = 历史会话；null = 未分配 */
type PaneSession = { kind: 'new' } | { kind: 'history'; id: string } | null

// App 新增 state（仅 home 视图语义）：
const [multiView, setMultiView] = useState(false)
const [panes, setPanes] = useState<PaneSession[]>([ { kind: 'new' }, null, null, null ])
```

- `multiView=false`：渲染现状 home（大标题 + ChatInput + ContextSelector）；
- 点击多视窗 btn：`multiView=true`，`panes` 若为初始值则置为 `[{kind:'new'}, null, null, null]`（当前会话 = 新对话，进左上）；
- 再次点击 btn：`multiView=false`（**窗格分配保留**，下次进入恢复，不重置会话状态——Mock 不持久化，刷新即回初始）；
- 窗格数据变更（×关闭 → 置 null / 选择器选中 → 装入）走 `setPanes` 更新对应下标。

### 3.2 组件拆分（全新 `src/components/home-grid/`）

```
src/components/home-grid/
├── HomeGrid.tsx        # 多视窗容器：btn + 2×2 grid + 四个 SessionPane（含 grid btn 角标）
├── HomeGrid.css        # grid/pane/输入条/＋菜单/选择器样式
├── SessionPane.tsx     # 单个窗格：标题栏 + 内容区三分发（未分配/新对话/历史会话）+ 底部输入条
├── MiniInputBar.tsx    # 简化输入条：[＋] [textarea] [发送] + ＋ 菜单（含二级选择）+ 附件行
├── SessionPicker.tsx   # 空窗格「＋ 打开会话」选择浮层（搜索 + 新对话 + 历史会话列表）
└── paneSessions.ts     # Mock 历史会话池与徽标推导（纯前端数据，Mock 于本地组件域）
```

> 组件族放独立目录 `home-grid/`，与既有 `project-detail/` 平级，保持「一个功能域一个目录」的现有惯例。

### 3.3 SessionPane（窗格三分发）

窗格内容按 `PaneSession` 三态分发：

| 态 | 中间区 | 底部输入条 | 标题栏 |
|---|---|---|---|
| `null` 未分配 | 气泡 icon +「此窗格还没有会话」+「＋ 打开会话」btn（触发 SessionPicker） | **不渲染** | 「未分配」灰字 + ×（关闭=维持 null，仅语义占位） |
| `{kind:'new'}` 新对话 | 居中轻提示：气泡 icon +「发送消息，开始新对话」+ 上下文小字（取 Mock 上下文） | MiniInputBar | PencilIcon +「新对话」+「当前会话」info 徽标 + × |
| `{kind:'history'}` 历史会话 | 消息流（Mock 消息渲染，复用 ChatMessage 视觉语言但用 pane 缩放样式） | MiniInputBar（插话语义） | ChatIcon + 会话名 + 状态徽标（运行中/Gate/手动）+ × |

- **× 关闭窗格**：将该格 `PaneSession` 置 `null`（回未分配态，非关闭整个多视窗）；
- **聚焦描边**：左上窗格（`index===0` 且会话非 null）带绿描边 `box-shadow: inset`（当前会话所在格），点击任意窗格切换聚焦格（Mock 简化：聚焦 = 最近点击的窗格）；
- **消息流**：历史会话 Mock 消息直接静态渲染（不接 engine；首页多视窗为 Mock 域，与项目详情 auto 引擎解耦，`不做的事`里明确边界）。

### 3.4 MiniInputBar（简化输入条）

```
┌────────────────────────────────────────────┐
│ [＋]  消息…（单行 textarea）        [ ↑ ]   │ ← pi-bar
│   ┌ ＋ 菜单（向上弹出）──────────────┐     │
│   │ 插入                             │     │
│   │  📎 添加附件                     │     │
│   │  @ 引用 · 长录音                 │     │
│   │ ─────────────────────            │     │
│   │ 设置（右侧当前值，点击切二级）     │     │
│   │  </> 编辑模式      自动接受编辑   │     │
│   │  ⚡ 运行模式       默认模式       │     │
│   │  🤖 模型           翼构·qwen3.8  │     │
│   │  📁 上下文         loomweb · dev │     │
│   └──────────────────────────────────┘     │
│ 🎙 录音.mp3 · 00:23 · 168KB          ×    │ ← 附件行（有附件时）
└────────────────────────────────────────────┘
```

- **状态**（每格独立）：`text`、`menuOpen`、`editMode/runMode/model/branch`（设置项，默认值同 ChatInput）、`attachment`（录音附件条，Mock）；
- **＋ 菜单**：分组「插入」（添加附件 / 引用·@长录音）与「设置」（编辑模式 / 运行模式 / 模型 / 上下文）；设置项 hover 显示当前值，**点击后内联展开二级选项列表**（复用菜单内子列表样式，点选项即切并收起二级）；「插入」项点击后合入对应 Mock 行为（附件 = 加附件条；长录音 = 打开 RecordingWidget 小窗，复用现有组件，`onAddToInput` 接 MiniInputBar 的附件行）；
- **发送**：空态灰置底禁用；有内容点亮，Enter 直发（Mock：清空 text，新对话格首条消息进消息流？——**不做**，发送仅清空输入，消息流 Mock 静态，见 §5 边界）；
- **外点关闭**：`document.mousedown` 监听（同 ChatInput 的 atMenu 模式）。

### 3.5 SessionPicker（会话选择浮层）

- 触发：空窗格「＋ 打开会话」btn；
- 形态：窗格内绝对定位浮层（居中上浮），白底圆角 12px + 阴影（同 atMenu/tpm 视觉）；
- 结构：搜索框（Mock 过滤）→ 分组「新对话」（空白新对话项）→ 分组「历史会话 · loomweb」（列表）；
- 历史会话池（Mock，`paneSessions.ts`）：

```ts
interface PaneHistorySession {
  id: string
  name: string            // 会话名
  badge: 'Gate' | '运行中' | '手动'   // 徽标 → tone: info/success/neutral
  badgeText?: string      // 如 '运行中 3/5'
  messages: RunMessage[]  // Mock 静态消息（含 ADE/人/系统）
}
```

- 选中「空白新对话」→ 该格 `PaneSession={kind:'new'}`；选中历史 → `{kind:'history', id}`；
- 搜索按 name 包含匹配实时过滤；点击外部 / Esc 关闭浮层；
- 已在**其他窗格**打开的会话在选择器里**置灰不可选**（tooltip「已在其他窗格打开」）。

## 4. 交互细节

1. 首页右上角点「多视窗」btn → 主区切 2×2，新对话进左上（绿描边聚焦），其余三格未分配占位；btn 高亮 + 角标 `1`；
2. 空窗格「＋ 打开会话」→ 浮层：选历史会话（如「周报生成 · 汇总统计」）→ 装入该格，消息流静态渲染，底部出现简化输入条（placeholder「插话…」）；
3. 选「空白新对话」→ 该格变新对话形态（居中轻提示 + 底部输入条）；
4. 任意窗格输入条「＋」→ 菜单向上弹：插入两项（附件/长录音）+ 设置四项（点开二级即切，右移当前值）；录音小窗「加入输入框」→ 该格输入条上方出现附件行；
5. 窗格「×」→ 该格回未分配占位（整窗不关）；仅剩左上格时 × 仍可用（该格可关成未分配，多视窗布局不变）；
6. 再点 btn → 恢复单窗口现状布局（panes 状态保留，再次切入不丢已开会话）；
7. 侧边栏「新对话」点击 → `view=home`（现状不变），若已在 home 多视窗则无副作用；
8. 选择器中已在其他窗格打开的会话置灰不可选；搜索实时过滤。

## 5. 不做的事（明确边界）

- **不接 automation engine**：多视窗历史会话消息为静态 Mock，不与项目详情 auto 引擎联动（首页域与项目域解耦）；
- 不做窗格比例拖拽调整（固定 2×2 等分）；
- 不做 1×2 / 1×3 等其他切分布局（仅 2×2，后续可扩展）；
- 发送消息**不产生新消息**（Mock 清空输入即完成闭环；首页多视窗会话消息流静态）；
- 多视窗状态**不持久化**（刷新回单窗口初始态）；
- 单窗口模式 ChatInput/ContextSelector 一律不动。

## 7. 增量 v2：滚动加载更多窗格（2026-10-22）

### 7.1 需求

**每屏固定展示 4 个窗格（2×2 占满视口）**；网格底部常驻一条「**滚动继续加载更多窗口**」入口——**滚动到底自动新增**一排 2 个新窗格（未分配），也可**点击立即新增**；无限增加，内容高度自然增长滚动。

> v2a（上滑手势+防抖+提示条）被本版替代：改为显式 load-more 条，交互更明确，每屏 4 格语义清晰。

### 7.2 交互设计

```
滚动容器（home-grid-scroll，overflow-y:auto）
┌─────────────视口────────────┐
│  [窗格1]  [窗格2]            │ ← 每屏 4 格占满
│  [窗格3]  [窗格4]            │
├────────────────────────────┤
│  [窗格5]  [窗格6]            │ ← 新增排（滚动可见）
│  ⌄ 滚动继续加载更多窗口        │ ← 常驻 load-more 条（内容底部）
└────────────────────────────┘
```

- **每屏 4 格**：行高 = 滚动容器高 / 2（`container-type: size` + `25cqh`，即视口半高），初始 2 行 4 格恰好占满、无滚动；
- **load-more 条**：常驻在网格内容**末尾**（滚动内容流内，非悬浮），文案「⌄ 滚动继续加载更多窗口」；**进入视口即自动新增一排**（IntersectionObserver），**点击立即新增**（手动路径）；
- **新增**：`panes` 数组**尾部追加 2 个 `null`**，网格长高；load-more 条随内容下移，再次滚到底又自动新增，循环无限；
- **数据不变量**：尾部追加，已有窗格会话分配不动；新排为未分配空窗格；
- **自动触发节流**：新增后 600ms 内不重复触发（防滚动惯性连发）；
- **关闭重开**：多视窗关闭时重置 `panes` = `INITIAL_PANES`（回初始 2×2；超 4 格分配丢弃，Mock 简化不持久化）。

### 7.3 实现要点

- `HomeGrid.tsx`：
  - 结构 `home-grid` > `home-grid-scroll`（滚动容器，`container-type: size`）> `home-grid-quad`（grid 2 列 × 动态行，行高 `max(25cqh, 260px)`）+ `load-more` 条（quad 之后，滚动流内）；
  - `useRef` 绑 load-more 条 + `IntersectionObserver`（rootMargin 提前 40px 触发）：进入视口 → 节流 600ms → `onGrowBottom()`；
  - load-more 点击：直接 `onGrowBottom()`（点击不节流？——**同样走节流时间戳**，保持一致防连点）；
- `HomeGrid.css`：`home-grid-scroll`（flex:1; min-height:0; overflow-y:auto; container-type:size）+ quad 动态行（`repeat(var(--hg-rows), max(25cqh, 260px))`）+ `load-more`（居中胶囊条：虚线描边 + ⌄ icon + 文案，hover 加深）；
- `App.tsx`：`handleGrowBottom()`（尾部 +2 null）；`toggleMultiView` 开启时重置 panes（已实现）。
