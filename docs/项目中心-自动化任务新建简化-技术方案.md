# 「项目中心 · 自动化任务」新建弹窗简化方案

> 创建日期：2026-08-31
> 更新日期：2026-08-31
> 前置文档：`项目中心-自动化任务交互改造方案.md`（新建弹窗现状来源）

## 1. 需求

新建任务弹窗**只保留两个字段**：

1. 任务名称（文本输入）
2. 选择工作流模板（下拉选择）

并在「选择工作流模板」处增加一个 **「去 ADE Teams 页面编辑」** 按钮。

**边界**：本期只做按钮占位，**不实现** ADE Teams 编辑页面与跳转逻辑。

## 2. 现状与差距

| 项 | 现状 | 目标 |
|---|---|---|
| 新建弹窗字段 | 任务名 / 触发方式 / 触发参数 / 人工介入（4 项） | 任务名 / 工作流模板（2 项） |
| 工作流模板概念 | 无（任务与流程无关联） | 任务创建时必须绑定一个模板 |
| ADE Teams 入口 | 无 | 模板选择处提供「去 ADE Teams 页面编辑」按钮（占位） |

## 3. 设计

### 3.1 新建弹窗布局

```
┌─ 新建任务 ────────────────────────────── × ┐
│                                            │
│  任务名                                    │
│  [ 如 每日构建 ______________________ ]    │
│                                            │
│  工作流模板                                │
│  [ 选择工作流模板 ▾________________ ]      │
│                                            │
│  ↗ 去 ADE Teams 页面编辑                  │ ← text-btn 小链接按钮
│                                            │
│                        [取消]  [创建]      │
└────────────────────────────────────────────┘
```

- 「创建」按钮禁用条件：任务名为空 **或** 未选择模板（两者都必填）；
- 「去 ADE Teams 页面编辑」按钮：本期点击无跳转（`title="即将上线"` 占位提示），样式沿用现有 `text-btn`，位于模板下拉框下方、右对齐，前缀 `↗` 表意外部跳转语义。

### 3.2 数据模型（`data/projects.ts`）

```ts
/** 工作流模板（ADE Teams 产出的流程定义，Mock） */
export interface WorkflowTemplate {
  id: string
  name: string
  /** 模板简介（下拉 option 无处展示，预留） */
  description: string
}

/** Mock 模板列表（模拟 ADE Teams 已发布的工作流） */
export const WORKFLOW_TEMPLATES: WorkflowTemplate[] = [
  { id: 'wf1', name: '每日构建与测试', description: '拉取代码 → 安装依赖 → 单元测试 → 构建产物' },
  { id: 'wf2', name: 'MR 静态检查', description: '拉取代码 → 静态检查 → 输出报告' },
  { id: 'wf3', name: '周报生成', description: '汇总数据 → 起草周报 → 等待确认 → 发布' },
  { id: 'wf4', name: '发布准备', description: '版本信息填写 → 预检 → 发布' },
]

export interface AutoJob {
  id: string
  name: string
  /** 绑定的工作流模板 id（新建时必选） */
  workflowId: string
  triggerType: '定时' | '事件' | '手动'
  triggerParam: string
  enabled: boolean
  needApproval: boolean
  currentRun?: JobRun
  history: JobRun[]
}
```

- `AutoJob` 新增 `workflowId` 字段；既有 Mock 任务按语义补绑对应模板（每日构建→wf1、MR 静态检查→wf2、周报生成→wf3、发布准备→wf4）；
- `triggerType` / `triggerParam` / `needApproval` **字段保留**：新建时不再采集，取默认值（`手动` / `手动触发` / `false`）；RunModal 编辑模式暂不改动（后续需求再统一）。

### 3.3 交互逻辑（`AutomationPanel.tsx`）

- 表单 state 简化为 `{ name, workflowId }`；
- `handleCreate`：校验两项均非空 → 生成 `AutoJob`（triggerType 默认 `'手动'`、triggerParam 默认 `'手动触发'`、needApproval 默认 `false`）；
- 任务行副标题展示：`任务名` 下方显示 `模板名 · 触发方式 · 触发参数 · 运行信息`（模板名替换原第一段，让绑定关系可见）。

### 3.4 「去 ADE Teams 页面编辑」按钮

```tsx
<button
  type="button"
  className="text-btn automation-wf-edit-btn"
  title="即将上线"
  onClick={() => { /* 本期占位：不跳转 */ }}
>
  ↗ 去 ADE Teams 页面编辑
</button>
```

- 样式：12px `text-btn`，置于模板字段下方右对齐（新增 `.automation-wf-edit-btn` 一条 CSS）；
- 本期点击无行为，仅保留入口可见性。

## 4. 文件改动清单

| 文件 | 改动 |
|---|---|
| `src/data/projects.ts` | 新增 `WorkflowTemplate` 类型 + `WORKFLOW_TEMPLATES` Mock 列表；`AutoJob` 增加 `workflowId`；既有任务数据补绑模板 |
| `src/components/project-detail/AutomationPanel.tsx` | 新建弹窗字段简化（名称+模板）；表单 state/handleCreate 调整；任务行副标题加模板名；模板字段下加「去 ADE Teams 页面编辑」占位按钮 |
| `src/components/project-detail/AutomationPanel.css` | 新增 `.automation-wf-edit-btn` 样式 |
| `README.md` | 自动化任务条目说明同步更新 |

不改动：RunModal（编辑模式字段保留）、useAutomationEngine、其余面板。

## 5. 验证方式

1. `npm run build` 通过（tsc 类型检查）；
2. 手动验证：新建弹窗仅两个字段；未选模板时「创建」禁用；创建后任务行显示模板名；「去 ADE Teams 页面编辑」按钮可见、点击无跳转。
