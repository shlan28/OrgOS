# 「自动化任务」任务弹窗阶段性结果与会话跳转方案

> 创建日期：2026-08-31
> 更新日期：2026-08-31
> 前置文档：`项目中心-自动化任务实时交互升级方案.md`（v2.1，任务运行弹窗 RunModal）、`项目中心-自动化任务消息头像-技术方案.md`（消息流说话人头像）

## 1. 需求

任务运行弹窗（RunModal）三点改造：

1. **阶段性结果**：每个流程阶段（步骤）完成时，返回更详细的阶段性结果，结果中的**文件以带下划线的可跳转 URL 展示**（Mock 演示用，点击新开标签页）；
2. **跳转会话按钮**：每个流程阶段提供一个「跳转到会话」按钮，可跳到该阶段对应的 ADE 会话；
3. **头部按钮改名**：右上角的「编辑」按钮改为「去 ADE Teams 编辑」。

## 2. 现状与差距

| 项 | 现状 | 目标 |
|---|---|---|
| 阶段性结果 | 步骤完成仅产出一条纯文本消息（如「单元测试完成。」） | 步骤完成产出**结果块**：摘要 + 产物文件列表（带下划线可跳转 URL） |
| 会话跳转 | 无 | 每个阶段结果块带「跳转到会话」按钮（Mock：新开标签页） |
| 头部「编辑」按钮 | `编辑` ⇄ `返回运行`（弹窗内切换编辑模式） | 改为 `去 ADE Teams 编辑`（外部跳转语义，沿用占位交互） |

## 3. 设计

### 3.1 数据模型（`data/projects.ts`）

```ts
/** 阶段性结果中的产物文件（带下划线可跳转 URL 展示） */
export interface ResultFile {
  /** 展示名（如 dist/index.html） */
  name: string
  /** 跳转地址（Mock：点击新开标签页） */
  url: string
}

/** 步骤阶段性结果（步骤完成时由 ADE 返回） */
export interface StepResult {
  /** 结果摘要（如「单元测试全部通过（58/58），覆盖率 87.4%」） */
  summary: string
  /** 产物文件（可跳转） */
  files: ResultFile[]
  /** 该阶段对应的 ADE 会话地址（「跳转到会话」按钮用） */
  sessionUrl: string
}

export interface RunMessage {
  // …现有字段不变…
  /** 阶段性结果（步骤完成消息附带；渲染为结果块） */
  result?: StepResult
}
```

- `result` 为**可选**字段：挂在「步骤完成」的 ADE 消息上；旧消息无该字段时按原样渲染，完全向后兼容；
- `sessionUrl` 放在 `StepResult` 内（每个阶段各自对应一个会话），而非消息级。

### 3.2 结果块渲染（`RunModal.tsx` MessageItem）

ADE 气泡内、消息文本下方追加结果块（仅当 `message.result` 存在）：

```
[A] ┌────────────────────────────────────────┐
    │ 单元测试完成。                           │ ← 原消息文本
    │ ┌────────────────────────────────────┐ │
    │ │ 阶段结果                             │ │ ← 结果块（浅蓝底 + 左边条）
    │ │ 单元测试全部通过（58/58），覆盖率 87.4% │ │
    │ │ 📄 test-report.html                 │ │ ← 文件：蓝色 + 下划线，点击新开
    │ │ 📄 coverage/lcov.info               │ │
    │ │                    [跳转到会话 ↗]    │ │ ← text-btn，新开标签页
    │ └────────────────────────────────────┘ │
    └────────────────────────────────────────┘
```

- **文件链接**：`--status-info` 蓝色 + `text-decoration: underline`，hover 加深；点击 `window.open(url, '_blank')`（Mock 地址如 `https://gitlab.aicoda.tech/fe/loomweb/-/artifacts/...`）；
- **跳转到会话**：结果块右下角 `text-btn`，同样新开标签页（Mock 地址如 `https://loom.aicoda.tech/session/st-xxxx`）；
- 结果块样式与 Gate 问题消息（橙色左边条）同族，但用**蓝色**（info）区分「产出」语义。

### 3.3 引擎（`useAutomationEngine.ts`）

`advanceRun` 完成步骤时，为「步骤完成」消息附带 `result`：

```ts
/** 按步骤名生成阶段性结果（Mock） */
const stepResultOf = (stepName: string, runIdStr: string): StepResult => { … }
```

- 以步骤名关键词（拉取/安装/测试/构建/检查/报告/汇总/生成/打包/归档…）匹配预置结果模板；未命中时给通用模板（摘要 + 1 个日志文件 + 会话地址）；
- 会话地址统一带 runId，保证「每个阶段一个会话」的语义：`https://loom.aicoda.tech/session/${runId}-st${idx}`。

### 3.4 Mock 数据（`data/projects.ts`）

为既有运行的消息流补 `result`（打开弹窗即可看到效果）：

- 「每日构建」当前运行（r11）：拉取代码 / 安装依赖 两条完成消息带结果块（文件 + 会话按钮）；
- 「每日构建」历史（r10）：4 个步骤全部带结果块（含构建产物 dist/ 文件）；
- 「MR 静态检查」（r8）：静态检查带 lint 报告链接；
- 「周报生成」当前运行（r12）：汇总数据带数据明细文件、生成周报带周报草稿文件；
- 「发布准备」（r13）：检查工作区带检查报告；
- yigou-app 的历史运行同样补齐（夜间打包 / 崩溃日志聚合）。

### 3.5 头部按钮（`RunModal.tsx`）

```
每日构建  [● 运行中] 2/4     [取消运行] [去 ADE Teams 编辑] [×]
```

- 原 `编辑` / `返回运行` 切换按钮**移除**（编辑模式入口整体下线，弹窗回归纯运行控制台）；
- 新按钮 `去 ADE Teams 编辑`：`text-btn` + `↗` 前缀，`title="即将上线"`，点击占位不跳转（与新建弹窗的「去 ADE Teams 页面编辑」占位按钮保持一致，ADE Teams 编辑页后续需求统一实现）；
- 编辑模式相关代码（mode state / 编辑表单 / handleSave）一并移除；任务改名等编辑能力后续由 ADE Teams 编辑页承接。

### 3.6 不改动的部分

- 消息流、Gate（确认/输入）、输入框、通知、任务列表交互均不变；
- `AutoJob` / `JobRun` / `RunStep` 结构不变（结果只挂在消息上，不侵入步骤模型）。

## 4. 验证

1. `npm run build` 通过（tsc + vite）；
2. Playwright 打开「每日构建」弹窗：结果块可见、文件带下划线可点、「跳转到会话」按钮可点、头部按钮文案为「去 ADE Teams 编辑」；
3. 手动触发一次运行，观察推进过程中的步骤完成消息带结果块。
