# 「用户设置页」技术方案

> 创建日期：2026-10-22
> 更新日期：2026-10-22

## 1. 背景与目标

在 `loom-org-os` 中补齐「个人设置」入口与页面：

1. **入口**：左侧边栏**左下角用户区**（头像 `S` + `shilu`）点击 → **向上弹出**用户菜单，菜单内含「**设置**」项；
2. **页面**：点击「设置」→ 主内容区（窗口右侧区域）从当前视图（首页 / 项目中心 / 项目详情）**整体切换为「设置页」**；
3. **设置页内容**：包含两项——
   - **① Agent 设置**：我的 ADE 列表（复用 ADE 配置弹窗）、默认模型、默认工具开关、知识库/MCP、ADE.md 个性化；
   - **② 邀请成员**：邀请链接 / 邮箱邀请、待接受邀请、组织成员管理。

约束与前提：

- 纯前端 Mock，**不接真实后端**，所有写操作仅本地 state 生效（与现有各面板一致）；
- 视觉、交互、命名**完全沿用现有体系**：浅色 macOS 风、CSS 变量、组件级 CSS、无第三方 UI 库；弹窗统一 `FormModal`，设置分组统一 `Section`/`Row`；
- 不破坏现有视图状态机：`home / project-center / project-detail` 行为零改动，仅**新增**一个 view 分支。

## 2. 现状分析

| 项 | 现状 | 复用结论 |
|---|---|---|
| 侧边栏用户区 | `Sidebar.tsx` 尾部 `.sidebar-user`（`.avatar` + `.username`），仅有 hover 样式，**无点击行为、无菜单** | 直接在此挂菜单（本次改动点） |
| 视图状态机 | `App.tsx` 的 `view: { type: 'home' \| 'project-center' \| 'project-detail' }` | 新增 `{ type: 'settings' }` 分支 |
| 页面容器 | `.page` / `.page-inner`（`width: min(960px,100%)`，padding 40/32/48） | 设置页外层直接复用 `.page`，内层用加宽容器（见 §4.1） |
| Settings 式样式 | `App.css`：`.section-label(-row)` / `.section-card` / `.settings-row(-main/-text/-title/-sub/-right)` / `.field-input/.field-select` / `.btn-primary/.btn-secondary/.text-btn(.danger/.ghost)` | 设置页**零新增通用样式**，仅写布局级 CSS |
| 「向上弹菜单」范式 | `MiniInputBar` 的 `.pi-menu`：`position:absolute; bottom: calc(100% + 6px)`，圆角 12px + 阴影 + `.pm-group` 分组 + `.pm-item` 行 | 用户名菜单照抄该范式（新增 `.user-menu*` 类） |
| ADE 配置能力 | `AdeSettingsModal.tsx`：名称/角色/关联项目/大模型底座/多模态/协作模型/个人知识库/MCP + 工具开关区（7 个工具卡片 + 全部/内置/IM 分组 + 全部开启/关闭） | **Agent 设置区「我的 ADE」行点击直接复用该弹窗组件** |
| ADE 常量与模板 | `data/projects.ts`：`ADE_TOOLS`(7) / `ADE_LLM_BASES` / `ADE_MULTIMODAL_MODELS` / `ADE_COLLAB_MODELS` / `ADE_KNOWLEDGE_BASES` / `ADE_MCP_SERVICES` / `ADE_MD_PLACEHOLDER` / `createDefaultAdeConfig()` | Agent 设置表单**复用同一批常量**，不新建字典 |
| 用户与成员数据 | `CURRENT_USER = { name:'shilu', initial:'S', color:'#5b7ba6' }`；`FOLDER_MEMBER_POOL = ['shilu','luyu','wang','chen','zhao','sun']`；`MEMBER_COLORS` / `memberColorOf()` | 邀请成员页的成员池与配色直接复用 |
| 通用组件 | `FormModal`(+`ModalField`)、`MultiSelect`、`Toggle`、`SegmentedControl`、`StatusBadge`、`SettingsRow` | 全部复用，无新增通用组件 |
| 图标 | `icons/index.tsx` 内联 SVG 线框（`GearIcon / RobotIcon / UsersIcon / PlusIcon / CheckIcon / ChevronDownIcon` 等） | 按需新增少量（如 `MailIcon`、`LinkIcon`） |

**结论**：本次为「1 个入口菜单 + 1 个新页面 + 2 个面板 + 少量数据模型」的增量改造，**不新增通用组件、不引入依赖**。

## 3. 总体设计

### 3.1 信息架构

```
侧边栏底部用户区（头像 S · shilu）  ← 点击
   └── 向上弹出用户菜单（.user-menu）
        ├─ 头部：头像 + 姓名 + 邮箱
        ├─ 分组「账号」：个人资料 · 偏好设置（占位）
        ├─ 分组「其他」：帮助与反馈（占位）
        └─ 设置  ← 点击进入
              │
              ▼
设置页（main-area 整体替换，view = 'settings'）
   ├─ 左侧设置导航（196px 固定列，分组标题「设置」）
   │    ├─ Agent 设置   ← 默认项
   │    └─ 邀请成员
   └─ 右侧内容区（滚动）
        ├─ [Agent 设置]  我的 ADE / 默认模型 / 默认工具 / 知识与上下文 / ADE.md
        └─ [邀请成员]    邀请方式 / 邮箱邀请 / 待接受邀请 / 组织成员 / 权限说明
```

### 3.2 视图与状态流

```
App.tsx
  type View = { type:'home' } | { type:'project-center' }
            | { type:'project-detail'; … }
            | { type:'settings'; section: SettingsSection }   // 新增

  Sidebar ──onOpenSettings()──▶ setView({ type:'settings' })
  SettingsPage 内部维护当前 section（'agent' | 'invite'）

  userSettings / invite 两组 state 挂在 App（与 projects 同级，不持久化）
```

- 侧边栏「新对话 / 项目中心」的 **active 判定需修正**：现为 `projectCenterActive={view.type !== 'home'}`，会把 settings 误判为项目中心选中，**必须改为** `view.type === 'project-center' || view.type === 'project-detail'`；
- 设置页**不显示**右上角多视窗 btn（该 btn 已限定 `view.type === 'home'`，无需改动）；
- 设置页顶部「‹ 返回」回到首页（Mock 简化，不做 prevView 记录，见 §8）。

### 3.3 数据模型

新增「用户级」设置数据文件 `src/data/settings.ts`：

```ts
export interface UserSettings {

  myAdes: AdeAgent[]
  /** 默认 ADE id */
  defaultAdeId: string
  /** 默认大模型底座 / 多模态 / 协作模型 */
  model: string
  multimodalModel: string
  collabModel: string
  /** 默认工具开关（key 见 ADE_TOOLS） */
  tools: Record<string, boolean>
  /** 个人知识库 / MCP 服务（多选） */
  knowledgeBases: string[]
  mcpServices: string[]
  /** ADE.md 个性化内容 */
  adeMd: string
}

export interface OrgMember {
  id: string; name: string; initial: string
  role: string                          // 职位
  permission: '所有者' | '管理员' | '成员'

}

export interface PendingInvite {
  id: string; email: string
  permission: '管理员' | '成员'

  invitedBy: string
}

export interface InviteData {
  link: string
  linkExpireDays: number                // 1 / 7 / 30
  linkPermission: '管理员' | '成员'
  pending: PendingInvite[]
}

export function createDefaultUserSettings(): UserSettings { … }
export function createDefaultInviteData(): InviteData { … }
export function isValidEmail(s: string): boolean { … }
```

- `myAdes` 初值：一条「研发工程师ADE」（复用 `createDefaultAdeConfig()` + `ADE_LLM_BASES[0]`）+ 一条「测试工程师ADE」，与现有申请专属 ADE 默认值同源；
- `OrgMember` 初值：`FOLDER_MEMBER_POOL` 6 人，`shilu` 为所有者，其余按现有项目成员职位填充；
- `InviteData.pending` 初值：2 条 Mock 待接受邀请；链接形如 `https://loom.aicoda.tech/join/8f3a-2c91`。

## 4. 页面设计

### 4.1 设置页整体布局

- 外层：`.page`（主区滚动容器）→ 页头 `.settings-page-head`（宽同内容容器，含 `.page-title`「设置」+ `.page-subtitle` + 右上角「‹ 返回」`.text-btn.ghost`）；
- 内层 `.settings-page`：`width: min(1040px, 100%)`，`display: flex; gap: 28px`：
  - 左栏 `.settings-nav`：宽 196px，`position: sticky; top: 0`，分组标题「设置」（`.section-label` 同规）+ 两项 `.settings-nav-item`（`RobotIcon` / `UsersIcon` + 文案），选中态 `background: rgba(0,0,0,.07)` + `font-weight:600`（与 `.menu-item.active` 一致）；
  - 右栏 `.settings-content`：`flex: 1; min-width: 0`，内容为 `Section` 分组卡片；
- 窄窗口（< 900px）降级：左栏改顶部 `SegmentedControl`（后续迭代，本次不做）。

### 4.2 面板一：Agent 设置

自上而下 5 个分组：

| 分组 | 行内容 | 交互 |
|---|---|---|
| **我的 ADE** | 分组右侧「＋ 申请专属 ADE」`text-btn`；每行 = `RobotIcon` + ADE 名 + 副标题「角色 · 大模型底座 · 当前：…」+ 状态徽标（工作中/空闲）+ 右侧「默认」徽标（默认项）/「设为默认」文字按钮（非默认项） | 点行 → **复用 `AdeSettingsModal`**（保存 / 移除写回 `myAdes`）；「设为默认」切换 `defaultAdeId`；工作中的 ADE 行仍可配置（个人设置语义，不受项目运行限制） |
| **默认模型** | 大模型底座（`ADE_LLM_BASES`）/ 多模态模型（`ADE_MULTIMODAL_MODELS`）/ 协作模型（`ADE_COLLAB_MODELS`，含空项「请选择协作模型」） | `Row` + 右侧 `.field-select`（宽 220px），**即改即存**（无保存按钮） |
| **默认工具** | 标题行 + 说明「关闭后，工具不可用，可**优化**上下文、**节省**Token用量」+ 已开启 `x / 7` + 「全部开启 / 全部关闭」；下方 7 个工具卡片两列网格（彩色徽标 + 名称 + `Toggle`；飞书/企业微信带橙色「尚未配置凭证」） | 复用 `ADE_TOOLS` 与 `Toggle`，即改即存 |
| **知识与上下文** | 个人知识库（`MultiSelect`）/ MCP 服务（`MultiSelect`） | 即改即存 |
| **ADE.md 个性化** | 分组右侧「编辑」`text-btn` → 行内展开 mono `textarea`（高 220px，占位 `ADE_MD_PLACEHOLDER`）+「有未保存的修改」+ 取消 / 保存 | 草稿模式，保存写 `adeMd` |

- 空态：`myAdes` 为空时显示「暂无 ADE，请先申请专属 ADE」。

### 4.3 面板二：邀请成员

自上而下 5 个分组：

| 分组 | 内容 | 交互 |
|---|---|---|
| **邀请方式** | `SegmentedControl` 两段「邀请链接 / 邮箱邀请」（默认邀请链接） | 切换下方表单；两段草稿独立保留 |
| **邀请链接**（段一） | 只读链接输入框（mono）+「复制」`btn-primary`（点击 → 「已复制」1.6s 还原）；有效期下拉（1/7/30 天，默认 7 天）；加入后权限下拉（管理员/成员，默认成员）；卡片底部行「重置邀请链接」`text-btn.danger` + 副标题说明（重置后原链接失效） | 复制用 `navigator.clipboard`，失败降级提示；重置无二次确认（与现有面板一致） |
| **邮箱邀请**（段二） | 输入框（多邮箱逗号/空格分隔）+ 权限下拉（管理员/成员）+「发送邀请」`btn-primary`（邮箱为空或格式非法时禁用 + `.form-hint.danger` 提示） | 发送后追加到待接受列表并清空输入；重复邮箱（已在成员或待接受列表）拦截提示 |
| **待接受邀请** | 行 = `MailIcon` + 邮箱（mono）+ 副标题「由 shilu 邀请于 … · 有效期 7 天」+ 权限徽标 + 右侧「重发 / 撤销」（撤销为 `.text-btn.danger`） | 撤销 = 移除；重发 = `sentAt` 刷新为当前时间；空态文案 |
| **组织成员** | 行 = 圆形头像（`memberColorOf` 底色 + 首字母）+ 姓名（当前用户带「我」徽标）+ 副标题「职位 · 权限 · 活跃于…」+ 在线点 + 右侧「移除」`text-btn.danger` | 移除 = 删除（无二次确认）；当前用户所有者行不可移除（唯一所有者保护，禁用 + title 提示）；卡片底部权限说明文案 |

- 权限说明（卡片底部灰色文字）：**所有者** = 拥有全部权限，可管理成员与组织配置（唯一所有者不可移除）；**管理员** = 可邀请与管理成员；**成员** = 可使用项目与 Agent 能力。

### 4.4 用户名向上菜单

- 触发：`.sidebar-user` 整行点击切换 `open`；`Escape` 关闭；点击菜单外部 `mousedown` 关闭（同 `Dropdown`/`MultiSelect` 实现范式）；
- 定位：`.sidebar-user-wrap`（`position: relative`）+ 菜单 `.user-menu { position:absolute; bottom: calc(100% + 6px); left: 8px; right: 8px; }`——**向上弹出**（贴用户区上沿），样式与 `.pi-menu` 同范式（白底 12px 圆角、`0 12px 36px rgba(0,0,0,.16)` 阴影、`padding: 5px`）；
- 结构：头部（头像 + 姓名 + 邮箱次级文案）→ `pm-sep` → 分组「账号」（个人资料 / 偏好设置，占位）→ `pm-sep` → 分组「其他」（帮助与反馈，占位）→ `pm-sep` → **「设置」**（`GearIcon`，点击关闭菜单 + 打开设置页）；
- 无障碍：`aria-haspopup="menu"` / `aria-expanded`；`.sidebar-user` 用 `<button>` 语义（width 100%、左对齐、`font-family: inherit`）。

## 5. 交互细节与边界

1. **菜单与视图联动**：从设置页再次点用户区 → 菜单仍可打开，「设置」项重复点击不重复 push；
2. **侧边栏高亮**：设置页时「新对话 / 项目中心」均非 active（修 `projectCenterActive` 判定）；
3. **设置页与项目数据互不影响**：只读写 `UserSettings` / `InviteData`，不触碰 `projects`；
4. **即改即存 vs 草稿**：模型/工具/知识库/MCP/邀请链接配置为即改即存；ADE 配置弹窗、ADE.md 编辑器为草稿 + 确定/保存（沿用现有习惯）；
5. **Escape 行为**：仅最上层浮层响应（菜单 / 弹窗）；
6. **剪贴板降级**：复制失败时按钮文案显示「复制失败，请手动选择」，1.6s 还原。

## 8. 待确认问题（需拍板）

1. **「Agent 设置」语义**：本方案定为**个人级 Agent 默认配置**（我的 ADE + 默认模型/工具/知识库/ADE.md），非项目 ADE；
2. **「邀请成员」组织层级**：按**单一组织**设计；若需多组织切换需追加组织选择器；
3. **返回行为**：定为回首页；如需「返回进入前视图」可加 `prevView` 记录；
4. **设置页左导航后续扩展**：结构已支持追加项（通知 / 快捷键 / 关于）；
5. **用户菜单占位项**：个人资料 / 偏好设置 / 帮助与反馈保留占位不实现；如希望菜单只留「设置」可精简。

## 9. 验收要点

- [ ] 点击左下角用户区 → 菜单**向上**弹出；点击外部 / `Escape` 关闭；
- [ ] 点「设置」→ 主区切换为设置页，左导航选中「Agent 设置」；侧边栏「项目中心」不被误高亮；
- [ ] Agent 设置：默认模型/工具/知识库/MCP 即改即存；「我的 ADE」点行弹出 ADE 配置弹窗（保存后行副标题刷新）；「设为默认」切换徽标；ADE.md 草稿保存/取消正确；
- [ ] 邀请成员：链接复制提示；重置链接变化；邮箱非法/重复拦截；发送后进入待接受列表；撤销/重发生效；成员列表头像/权限/「我」徽标正确，唯一所有者不可移除；
- [ ] 两个面板切换不丢已保存状态；
- [ ] 设置页无横向滚动条（左栏 sticky + 内容 `min-width: 0`）；
- [ ] 首页 / 项目中心 / 项目详情现有功能回归通过。
