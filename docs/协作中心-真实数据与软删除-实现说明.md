# 协作中心 · 真实数据与软删除实现说明

> 更新日期：2026-10-24
> 范围：项目 / 文件夹 / 项目成员 / 项目 agent / 软删除 / agent 运行状态。会话部分见 [会话真实化方案.md](会话真实化方案.md)。

## 1. 数据来源

| 内容 | 存储 | 说明 |
|---|---|---|
| 项目 | `projects` | 名称、简介、状态、起止日期、所属文件夹、`deleted_at` |
| 项目成员 | `project_members` | 只能来自设置页已导入成员（`org_members`） |
| 项目文件夹 | `project_folders` | `members_json`、`deleted_at` |
| 项目 agent | `agents.project_id` | 指向设置页的 Agent（`agents` 表） |
| 组织成员 | `org_members` | 设置页「成员管理」飞书导入 |
| Agent 运行状态 | 由 `sessions.status` 派生 | 不落配置 |

## 2. 项目成员

- 「编辑项目 → 添加成员」只能从设置页已导入成员中选择（`orgApi.members()`），不再允许手填姓名
- 职位 / 权限仍按项目单独设置；组织权限会映射默认项目权限（所有者 → 项目负责人，管理员 → 管理员，成员 → 无）
- **创建者自动成为项目成员并固定为「项目负责人」**：`POST /api/projects` 在服务端补齐，避免前端漏传
- 加载项目时按设置页成员名单过滤，非设置页来源的历史成员不会显示；历史数据已一次性清理

## 3. 项目 agent

- 项目 agent = 设置页 Agent 中 `project_id` 指向该项目的记录，展示数据与设置页同源
- 「编辑项目 → 项目 agent」可从设置页已配置 Agent 中添加（`PATCH /api/agents/:id { projectId }`）
- 「移除」只解除项目绑定（`projectId: null`），不删除 Agent 本身
- 项目没有 agent 时，会话列表禁用「＋ 新会话」

## 4. 文件夹

- **创建**：创建者自动成为文件夹成员，角色固定为 `owner`（服务端兜底）
- **编辑**：所有者、成员都改为从设置页成员多选；打开时过滤掉非设置页成员；没有所有者时默认当前登录用户（若在设置页成员中）
- **软删除**：`DELETE /api/project-folders/:id` 只写 `deleted_at`；文件夹从列表消失，内部项目 `folder_id` 置空（移至未分组），数据保留
- 历史文件夹成员已按设置页名单清理（`members_json` 只保留 `org_members` 中的名字）

## 5. 项目软删除

- 入口：项目卡片 ⋯ 菜单「删除项目」、编辑项目弹窗底部「删除项目」
- 二次确认（红色按钮 + tips 说明），确认后 `DELETE /api/projects/:id`
- 后端写 `projects.deleted_at`，列表 / 详情自动过滤；成员、会话、Agent 绑定等数据保留
- 在项目详情页删除成功后自动退回协作中心

## 6. Agent 运行状态

`GET /api/agents` 返回的 `status` / `currentTask` 由后端实时派生：

- 存在 `sessions.status = 'running'` 的会话 → `工作中`，`currentTask` = 最近一条运行中会话标题
- 否则 → `空闲`，`currentTask` 为空
- `config_json.status / currentTask` 不再作为数据源，也不再写入

前端刷新时机：进入项目、发送消息（busy 开始）、turn 结束、打开设置页。

已知边界：服务进程在 turn 中途退出时，会话可能停留在 `running`，agent 会持续显示「工作中」，后续可加超时清理。

## 7. 界面与文案

- 侧栏「项目中心」→「协作中心」，页面标题、面包屑、软删除说明同步改名
- 移除侧栏「定制」入口
- 删除项目 / 文件夹确认弹窗统一使用红色确认按钮 + tips 说明块（`.form-tips`）

## 8. 验收清单

1. 新建项目后，创建者在项目成员中且为「项目负责人」
2. 新建文件夹后，创建者为 `owner`
3. 编辑项目 / 文件夹时，成员与所有者只能从设置页成员中选择
4. 删除项目后列表消失，数据库行仍在（`deleted_at` 有值）
5. 删除文件夹后列表消失，内部项目出现在未分组
6. 发送会话消息时对应 agent 显示「工作中」，turn 结束回到「空闲」
