# 「新建任务创建成功」提示改为正式弹窗方案

> 创建日期：2026-08-31
> 更新日期：2026-08-31（v3：Toast 改为页面正中正式弹窗，双按钮凸显；v2 Toast 方案已实现并提交 00fc640，本版推翻）
> 前置文档：`项目中心-自动化任务新建简化-技术方案.md`（新建弹窗两字段来源）

## 1. 需求

1. **去掉弹窗内「↗ 去 ADE Teams 页面编辑」按钮**（已实现，保持）；
2. 创建任务成功后的提示**不用底部 Toast**，改为**正式弹窗，放在页面正中间**：
   - 「去 ADE Teams 编辑」和「关闭」是 **2 个按钮**，要**凸显出来**（正式按钮样式，不是链接小字）；
   - 仍然不自动消失，必须主动点按钮才关闭。

## 2. 设计

### 2.1 弹窗形态（复用 FormModal 的遮罩/居中/动画语言）

```
┌─ 遮罩（点击不关闭，强制按钮操作）────────────────────┐
│                                                      │
│        ┌─ 创建成功 ────────────────────── × ┐        │
│        │                                    │        │
│        │           ✓（绿色大图标）           │        │
│        │        任务「冒烟测试」创建成功       │        │
│        │   可在 ADE Teams 中编辑该任务的工作流  │        │
│        │                                    │        │
│        │    [去 ADE Teams 编辑 ↗]  [关 闭]   │        │ ← 两个正式按钮
│        └────────────────────────────────────┘        │
│                                                      │
└──────────────────────────────────────────────────────┘
```

- **位置**：页面正中央（复用 `modal-overlay` 居中遮罩语言）；
- **标题**：「创建成功」；
- **主体**：绿色 ✓ 成功图标（40px 圆形浅绿底）+ 主文案「任务「xxx」创建成功」+ 次级说明「可在 ADE Teams 中编辑该任务的工作流」；
- **按钮区**（凸显，两个都是正式按钮）：
  - `去 ADE Teams 编辑 ↗`：**主按钮**（`btn-primary`，实心蓝底白字）——本期占位不跳转（`title="即将上线"`）；
  - `关闭`：**次按钮**（白底描边 `btn-secondary`）；
- **不自动消失**：无定时器；点「关闭」或「去 ADE Teams 编辑」都关闭弹窗（编辑按钮占位无跳转，关闭后留在任务列表）；
- 遮罩点击**不**关闭（区别于 FormModal 的点遮罩关闭——成功提示需要明确的按钮操作，避免误触丢失入口）；
- Escape 键可关闭（macOS 标准）。

### 2.2 组件实现（`components/project-detail/CreateJobSuccessModal.tsx`）

- 新组件，不复用 FormModal（FormModal 是表单容器：取消/确认文案与语义不符，且点遮罩会关闭）；
- Props：`jobName: string`、`onClose: () => void`；
- 样式文件 `CreateJobSuccessModal.css`，遮罩/圆角/阴影/动画对齐 FormModal。

### 2.3 AutomationPanel 改造

- 删除 `Toast` 引用与 `components/Toast.tsx` / `Toast.css`；
- `handleCreate` 成功后 `setSuccessJobName(job.name)` 打开成功弹窗；
- 弹窗常驻，点任一按钮关闭。

### 2.4 按钮样式（新增 `btn-secondary`，App.css）

```css
.btn-secondary {
  /* 白底 + 边框 + 主文字色，与 btn-primary 同高同圆角 */
}
```

## 3. 验证

1. `npm run build` 通过；
2. Playwright：创建任务 → 页面正中出现「创建成功」弹窗（✓ 图标 + 文案 + 两个按钮）→ 等待 5s 不消失 → 点「关闭」消失；再建一个任务 → 点「去 ADE Teams 编辑」弹窗关闭（占位无跳转）。
