# 项目中心 · 项目知识库索引化 —— 技术方案

> 创建日期：2026-10-23
> 更新日期：2026-10-23（**实施完成**：原型图确认 + 索引详情改弹窗 + 片段预览全量分页（每页 10 条，固定 footer）+ 详情弹窗加宽 1 倍（1040px）；Playwright + 读图全 PASS，见第 8 节）

## 1. 需求

鹿鹿子大王：「项目知识库」子 tab 从现在的「目录树 + 文档列表 + 导入/编辑」改成**收录清单 + 索引状态 + 检索测试**（示意图）：

```
[ 文档 ]  [ 项目知识库 ]                      ← 分段不变
─────────────────────────────────────
收录 12/18  已索引 10  索引中 1  失败 1  片段 486
                              [检索测试] [⋯ 批量]
─────────────────────────────────────
目录树(只读)  │  [全部][已收录][未收录][需处理] [搜索]
产品 5/7      │  文档行：名称 + 状态徽标 + 路径·片段·时间 + 开关
研发 3/4      │
未分组 4/7    │  点击行 → 索引详情（片段预览 / 重建 / 在飞书中打开）
```

**索引状态机**：

```
off ──开──▶ pending ──▶ indexing ──▶ indexed
                indexing ──失败──▶ failed ──重试──▶ indexing
                indexed ──文档更新──▶ stale ──重建──▶ indexing
                indexed/failed/stale ──关──▶ off（片段数清零）
```

## 2. 现状与差距

| 项 | 现状 | 差距 |
|---|---|---|
| 项目知识库子 tab | `DocLibraryView`（目录树可增删改 + 文档列表 + 导入弹窗 + 预览/编辑二级页），与「文档」子 tab 同构复用 | 需全新「收录清单」形态；导入/编辑/目录管理全部移除 |
| `KbDoc` | title/source/sourceRef/markdown/content/summary | 缺索引状态、片段数、索引时间、失败原因 |
| Mock 数据 | loomweb 知识库 3 篇文档 3 目录 | 按示意图扩为 18 篇 / 收录 12 / 已索引 10（含 stale）/ 索引中 1 / 失败 1 / 片段 486 |
| 状态机 | 无 | 需 Mock 定时推进（pending → indexing → indexed/failed） |
| 检索测试 | 无 | 需查询弹窗 + Mock 命中结果 |

## 3. 方案

### 3.1 数据层（`projects.ts`）

```ts
/** 知识库文档索引状态机（项目知识库收录清单用） */
export type KbIndexState = 'off' | 'pending' | 'indexing' | 'indexed' | 'failed' | 'stale'

export interface KbDoc {
  // ……现有字段不动（title/folderId/source/sourceRef/…，与「文档」子 tab 共享类型）
  /** 索引状态；缺省 off = 未收录（「文档」子 tab 的 documents 不带该字段） */
  indexState?: KbIndexState
  /** 已索引片段数（off 清零；统计条「片段」= 全库求和） */
  chunks?: number
  /** 最近一次索引完成时间（indexing 结束刷新） */
  indexedAt?: string
  /** failed 时的失败原因 */
  errorText?: string
}
```

**loomweb 知识库 Mock 重做（对齐示意图数字）**：目录 = 产品 / 研发（平铺）+ 未分组（无 folderId 文档，目录树固定渲染一个「未分组」聚合节点）：

| 目录 | 文档数 | 收录 | 分布 |
|---|---|---|---|
| 产品 | 7 | 5 | indexed 3 + stale 1 + indexing 1 + off 2 |
| 研发 | 4 | 3 | indexed 2 + failed 1 + off 1 |
| 未分组 | 7 | 4 | indexed 4 + off 3 |
| **合计** | **18** | **12** | indexed 9 + stale 1 + indexing 1 + failed 1 + off 6 |

- 统计条实时聚合：**已索引 10** = indexed 9 + stale 1（stale 本质是已索引但过时）；**片段 486** = 已索引文档 chunks 求和（Mock 分配 50/42/38/44/58/46/60/52/48/48）
- **需处理**过滤 = failed + stale + pending
- yigou-app 知识库 2 篇补 `indexState`（1 indexed 1 off）；data-pipeline 空库不变

### 3.2 组件结构（新 `KbIndexPanel.tsx`）

```
KnowledgePanel（分段壳不动）
├─ 文档        → DocLibraryView（不动）
└─ 项目知识库  → KbIndexPanel（新，替换 DocLibraryView）
    ├── 统计条：chips（收录 x/y · 已索引 · 索引中 · 失败 · 片段）+ [检索测试] [⋯ 批量]
    ├── 双栏：左目录树（只读，节点显示 收录数/总数，点节点过滤右栏）
    │         右列表：过滤分段 [全部][已收录][未收录][需处理] + 搜索框 + 文档行
    ├── 文档行：名称 + 状态徽标 + 次级（路径 · 片段 N · 时间）+ 收录开关
    └── 索引详情**弹窗**（点行打开，鹿鹿子大王确认）
        ├── 状态徽标 + 路径/片段/索引时间/失败原因
        ├── 操作：[重建]（→ indexing 走状态机）/ [在飞书中打开]（外链 sourceRef）
        │        failed 时 = [重试]；indexed 时附 [模拟文档更新]（→ stale，演示状态机）
        └── 片段预览：**全量片段 + 分页（每页 10 条）**；分页条固定弹窗底部 footer（滚动区外）
```

- 状态徽标配色：indexed 绿 / indexing 青蓝呼吸动画 / pending 灰蓝 / failed 红 / stale 橙 / off 灰「未收录」
- 目录树**只读**：删 + 新建目录 / 重命名 / ⋯ 菜单；「未分组」节点显示无 folderId 文档聚合

**实施追加（鹿鹿子大王）**：
- 索引详情为**弹窗**（非二级页）且**宽度加大 1 倍 = 1040px**（max-width 兜底窄视口）
- 片段预览**展示所有片段**：`chunkListOf(doc)` 以 content 小节为种子按 chunks 数循环派生（续 N 变体），**每页 10 条**分页；分页条（共 N 条 · 第 x/y 页 + 上一页/页码/下一页，页码窗口带 … 省略）**固定在弹窗底部 footer**，不随 chunk 滚动区滚动（首末页按钮禁用态）
- 状态机读最新 state：`docsRef`（useRef 同步最新 docs）——setTimeout 闭包里旧 `knowledge` 会让状态机卡在排队中，已修复

### 3.3 状态机 Mock（KbIndexPanel 内）

- **开**：off → `pending`（立即）→ 600ms → `indexing` → 再 1200ms → `indexed`（写回 chunks ≈ 40–60 随机、indexedAt；**演示可控：Mock 里新开的一律成功**）
- **重试/重建**：failed/stale/indexed → `indexing` → 1200ms → `indexed`
- **失败**：仅初始 Mock 数据里的失败文档演示；重试后成功
- **文档更新**：详情页「模拟文档更新」→ indexed → `stale`
- **关**：立即 → `off`，chunks 清零
- 定时器用 `setTimeout` 链 + `onUpdateKnowledge` 写回；面板卸载后仍写父级 state（React 18 安全，Mock 可接受）
- 批量（⋯ 菜单）：`收录全部未收录` / `取消全部收录` / `重建全部索引`（对目标集合逐个走状态机）

### 3.4 检索测试弹窗（面板内嵌）

- 入口：统计条右侧 [检索测试]
- 弹窗：查询输入框 + [测试] → 800ms 模拟 → 结果列表：命中片段行（所属文档名 + 片段文本 + 相似度 0.xx Mock）
- Mock 匹配逻辑：在已索引（indexed/stale）文档的 content 文本里做关键词包含匹配；无命中显示空态

### 3.5 移除项

- 项目知识库段的 `+ 导入` 弹窗、文档预览/编辑二级页（DocLibraryView 不再用于 kb 分支）、目录增删改名菜单——**「文档」子 tab 的 DocLibraryView 全部保留不动**

## 5. 验证结果（已实施完成）

1. `npm run build` 通过（tsc 类型检查）
2. Playwright（loomweb 详情页，1280×720，实测数值）：
   - 统计条：收录 12/18 · 已索引 10 · 索引中 1 · 失败 1 · 片段 486（精确匹配）
   - 目录树只读：全部文档 12/18 / 产品 5/7 / 研发 3/4 / 未分组 4/7；无新建/⋯ 菜单
   - 过滤：「需处理」= 2 行（failed + stale）；「未收录」= 6 行；搜索「支付」正常过滤
   - 状态机：开开关 → 排队中 → ~600ms 索引中 → ~1200ms 已索引（片段 40–60 随机、indexedAt 刷新）；统计条实时联动（13/18 · 已索引 11 · 片段 +N）
   - 索引详情弹窗：宽 1040px 居中；片段预览全量 52 条 → 第 1/6 页恰 10 卡（#001–#010）；翻第 2 页从 #011 起、页码高亮跟随、首末页按钮禁用；**分页条固定弹窗底部**（几何实测 foot bottom ≤ modal bottom，滚动区外）
   - 失败文档详情：「重试索引」+ 失败原因行；重试 ~1200ms 后已索引
   - 检索测试：预填词命中 6 条（文档名+徽标+分数+文本降序）；无命中空态正常
   - 批量菜单三项可见可点（取消全部收录后统计归零）
