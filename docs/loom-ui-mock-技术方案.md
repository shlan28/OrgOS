# Loom 应用界面模拟 - 技术方案

> 创建日期：2026-08-26
> 更新日期：2026-08-26

## 1. 背景与目标

根据用户提供的截图（`截屏2026-08-26 13.18.01_1.png`），用代码还原一个 macOS 风格的 **Loom** AI 编程助手桌面应用界面。目标是像素级还原截图中的静态页面效果，并附带基础交互（悬停、输入、下拉展开等），输出为可直接在浏览器打开的单页应用。

## 2. 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 框架 | React 18 + Vite | 用户指定 React；Vite 构建快、开发体验好 |
| 语言 | TypeScript | 组件 Props 类型清晰，便于维护 |
| 样式 | CSS Modules（或组件级 CSS） | 页面为静态模拟，无需引入 UI 库，样式隔离干净 |
| 图标 | 内联 SVG 封装为 React 图标组件（SF Symbols / Lucide 线框风格，1.5px 描边） | 截图图标均为细线框风格，SVG 可精确控制且无外部依赖 |
| 字体 | `-apple-system, "SF Pro Text", "PingFang SC", "Helvetica Neue", sans-serif` | 还原 macOS 原生字体观感 |
| 状态管理 | React useState（组件内局部状态） | 交互轻量（分段切换、下拉、输入），无需全局状态库 |

## 4. 交互设计（轻量）

- 侧边栏菜单项 / 分段控件：hover 高亮，点击切换选中样式（Home/Code 可切换）
- 输入框：可聚焦输入，占位符"可向 Loom 询问任何事"
- 发送按钮：输入内容为空时保持禁用灰态；有内容时变为可点击态（深色）
- 下拉按钮（自动接受编辑/默认模式/模型选择/项目/分支）：点击弹出简单下拉菜单，可切换选项
- 窗口按浏览器视口自适应，内容区最小宽度保护

## 6. 验收标准

1. 打开页面后布局与截图一致：左侧边栏 + 主内容区，各元素位置、文字、颜色还原
2. 交通灯按钮、分段控件选中态、绿色"自动接受编辑"、灰绿发送按钮等关键视觉点齐全
3. 基础交互可用（输入、下拉、hover）
4. 完成后提交 git commit
