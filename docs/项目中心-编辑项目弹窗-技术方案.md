# 「项目详情页 · 编辑项目」弹窗方案

> 创建日期：2026-08-31
> 更新日期：2026-08-31
> 前置文档：`项目中心-新建项目-技术方案.md`（新建弹窗字段来源）

## 1. 需求

项目详情页**缺少编辑项目基本信息的入口**：进入详情后无法修改项目名、简介、状态、周期等，只能删了重建。补一个「编辑项目」弹窗。

## 2. 现状与差距

| 项 | 现状 | 目标 |
|---|---|---|
| 详情页头部 | 返回按钮 + 项目名 + 状态徽标 + 简介行，无操作入口 | 头部右侧加「编辑」按钮，打开编辑弹窗 |
| 编辑能力 | 无（新建后字段不可改） | 弹窗编辑：项目名/简介/所属文件夹/状态/开始日期/截止日期 |
| 数据通道 | `ProjectDetail` 已有 `onUpdateProject`（各面板写操作共用） | 复用该通道更新项目基础字段 |

## 3. 设计

### 3.1 入口与布局

详情页头部标题行右侧加「编辑」文字按钮（`text-btn`，与全局风格一致）：

```
[← 返回项目中心]

[📁 loomweb] [进行中]                              [编辑]
Loom Web 端研发 · 创建于 2026-07-02 · 周期 2026-07-02 ~ 2026-09-30
```

- `detail-header` 改为 `justify-content: space-between`，左侧名称+徽标、右侧编辑按钮；
- 编辑按钮无禁用条件（项目随时可编辑）。

### 3.2 编辑弹窗（复用 FormModal，字段与新建弹窗对齐）

```
┌─ 编辑项目 ───────────────────────────── × ┐
│  项目名    [ loomweb___________________ ]  │
│  简介      [ Loom Web 端研发___________ ]  │
│  所属文件夹 [ 研发线 ▾ ]                   │
│  状态      [ 进行中 ▾ ]                   │
│  开始日期  [ 2026-07-02 ]                 │
│  截止日期  [ 2026-09-30 ]                 │
│                    [取消]  [保存]          │
└────────────────────────────────────────────┘
```

- 打开时表单**预填当前项目字段**；
- 校验规则与新建弹窗一致：名称/简介/两日期必填；**项目名不可与其他项目重名（排除自身）**；截止日期 ≥ 开始日期；
- 「保存」禁用条件 = 任一校验不通过；
- 保存后头部名称/徽标/简介行即时刷新（数据驱动，无需额外处理）。

### 3.3 数据流

```
App（projects + folders state）
  │  传 projects / folders 给 ProjectDetail（校验用）
  ▼
ProjectDetail
  │  编辑弹窗确认 → onUpdateProject(project.id, p => ({ ...p, ...form }))
  ▼
App.handleUpdateProject → setProjects → 详情页头部自动刷新
```

- `folderId` 变更走同一 updater（与卡片「移动到」菜单等效）；
- 不改动 `createdAt`（创建时间不可编辑）。

## 4. 文件改动清单

| 文件 | 改动 |
|---|---|
| `src/components/ProjectDetail.tsx` | 新增 `projects`/`folders` props；头部加「编辑」按钮；编辑弹窗（FormModal 6 字段 + 校验 + 保存） |
| `src/components/ProjectDetail.css` | `detail-header` 布局调整（左右分布）+ 编辑按钮区样式 |
| `src/App.tsx` | 向 ProjectDetail 传 `projects` / `folders` |
| `README.md` | 详情页说明补「编辑项目」条目 |

不改动：ProjectCenter 新建弹窗、ProjectCard 菜单、各详情面板。

## 5. 验证方式

1. `npm run build` 通过；
2. 手动验证：详情页头部出现「编辑」；弹窗预填当前值；改名重名时保存禁用并提示；改状态/日期后头部徽标与周期行即时变化；改所属文件夹后返回列表页项目归入新文件夹。
