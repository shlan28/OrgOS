# 「详情页四格布局：会话列表 + 会话详情 + Terminal + 工作流」技术方案

> 创建日期：2026-10-22
> 更新日期：2026-10-22

## 0. 需求（鹿鹿子大王）

项目中心详情页改为**从左到右 4 列 4 个格子**，格子间有间距，每个格子圆角：

| 格 | 内容 | 来源 |
|---|---|---|
| 1 | **会话 list**（常驻，替代原 🕘 icon 覆盖式抽屉） | 新组件 |
| 2 | **会话详情**（消息流 + 插话） | 现 ChatPane 主体 |
| 3 | **Terminal**：agent 调用工具的日志，terminal 文字风格（深底 mono） | 新组件 + 新数据 |
| 4 | **工作流**（现有多个 tab 的格子，可切换不同 tab；**tab 切换/打开/关闭交互不变**） | 现 detail-config 原样入格 |

## 1. 现状与问题

| # | 现状 | 问题 |
|---|---|---|
| 1 | 双栏：左 ChatPane（34%）+ 右 tab；历史会话藏在 🕘 覆盖式抽屉 | 会话列表不可见、切换两步操作 |
| 2 | agent 执行过程只有对话式消息流 | 无工具调用日志视图，缺少「执行细节」的观察窗口 |

## 2. 布局设计

> **示意图**：`docs/项目中心-详情页四格布局-设计图.html`（浏览器打开，静态还原四格排布/列宽/格子语言/各格头部与内容示意，含四格标注说明）。

### 2.1 结构（detail-page → detail-grid）

```
detail-page
└── detail-grid                     ★改为 flex 容器：4 格 + 3 根拖拽条 + padding 8px（灰底露间隙）
    ├── SessionRail（格1）            ★新：常驻会话列表（头部右上角 ＋ 新会话）
    ├── .cell-resizer（6px 拖拽条）    ← 格 1｜2 间隙：左右拖拽调列宽
    ├── ChatPane（格2）               改：纯会话详情单格（受控 props，状态上提）
    │   └── MembersDrawer             成员覆盖式抽屉（保留，格内显示）
    ├── .cell-resizer                ← 格 2｜3 间隙
    ├── TerminalPane（格3）           ★新：ADE 工具调用日志（浅底 mono 日志风格）
    ├── .cell-resizer                ← 格 3｜4 间隙
    └── detail-config（格4）          原 ClosableTabs + detail-panel，套格子皮
```

- **格子语言**（`.detail-cell` 公共类）：白底、`border: 1px solid var(--border)`、`border-radius: 10px`、`overflow: hidden`、纵向 flex；间隙/拖拽条/四周 padding 露出 `detail-grid` 的灰底（`#eef0f2`）形成「四张卡片浮在画布上」的效果；
- **实现方式**：CSS grid → **flex 布局**。拖拽条 `.cell-resizer` 自身占位 6px（= 视觉间隙，紧凑），既是间隙又是拖拽热区（热区窄但格间贴得近，中央 3px 竖线 hover/拖拽中高亮）；四格宽度由 JS 内联 style 控制（`flex: 0 0 {w}px`），支持逐列拖拽调节（见 2.3）；
- **默认列宽**（主区 ≈1022px，去 padding 16 + 拖拽条 18 → 四格共 988px）：格 1 = 168px 固定起点，剩余按 `1.15 : 0.9 : 1.1` 比例分配：

```css
.detail-grid {
  display: flex;          /* grid → flex：拖拽条占位 = 视觉间隙 */
  padding: 8px;           /* 紧凑：12px → 8px */
  background: #eef0f2;
}
.detail-cell { flex: 0 0 auto; } /* 宽度 JS 内联控制 */
.cell-resizer { flex: 0 0 6px; cursor: col-resize; /* 中央 3px 竖线高亮 */ }
```

1022px 视口下默认 ≈ 168 / 298 / 233 / 289；更宽窗口按比例增长，用户拖拽后按 2.3 规则管理。

### 2.2 各格头部（统一 40px 高度对齐）

四格头部**统一高度 40px**（`box-sizing: border-box`，flex 垂直居中；格 4 tab 条底线贴边框对齐），视觉上一条水平线贯穿四格。

| 格 | 头部 |
|---|---|
| 1 会话列表 | **`项目名（可点击）· 会话`**（点项目名 = 编辑项目弹窗，hover 微底提示可点；项目名次级着色，单行省略）+ 总数徽标；**右上角 ＋ 新会话 icon**（无文字；无底部按钮区，无未读字样——未读只体现在条目小徽标） |
| 2 会话详情 | **单行头部 = 当前会话行**：会话名（ellipsis）+ 自动化 tag + 👥 成员 icon；**无编辑按钮**（入口 = 格 1 点项目名）、无项目名/状态行、无返回按钮（返回项目列表走应用侧边栏「项目中心」菜单）；简介/周期/状态移入 title tooltip |
| 3 Terminal | `ADE 工具日志` + 当前会话名（ellipsis）；**无交通灯三点装饰**，深色终端视觉一并移除（见 4.2） |
| 4 工作流 | 即 ClosableTabs 本身（tab 条 + ＋ 菜单原样，容器高度钳到 40px），格子顶部不再加额外标题 |

### 2.3 列宽拖拽调节（新）

四格宽度**逐格独立、可直接拖拽调节**，三根拖拽条分别管理相邻两格的宽度分配：

**交互规则**：

| 规则 | 设计 |
|---|---|
| 拖拽热区 | 拖拽条全高 6px 宽（= 视觉间隙），`cursor: col-resize`；中央 3px 竖线，hover / 拖拽中高亮（灰 → 青蓝） |
| 拖拽行为 | `mousedown` 记录起点 → `mousemove` 计算 delta → 更新**左侧格宽 = 起始宽 + delta**，右侧相邻格**反向增减**吸收 delta（其余两格不动） |
| 最小宽度 | 每格 min 120px（rail 168 / chat 260 / term 200 / config 240；取 120 统一简化），触底后不再压缩、delta 丢弃（右侧格也已到 min 时拖不动） |
| 最大宽度 | 拖到某格 max = 容器宽 − 其余三格 min（即不把别的格挤到 min 以下） |
| 双击重置 | 双击拖拽条 → 四格恢复默认比例（168 / 按剩余 1.15:0.9:1.1 分配） |
| 拖拽中 | body `user-select: none` + 拖拽条 active 态；`mouseup`/`mouseleave` window 级监听结束，防拖出窗口卡死 |
| 窗口缩放 | 宽度不跟随重算（Mock 简化）；更宽/更窄时保持用户设定，第 4 格作为 flex 吸收余量（见下） |
| 持久化 | 不做（Mock 演示；备注：后续可接 localStorage） |

**宽度状态与实现**：

```tsx
// ProjectDetail state（列宽组）
const [widths, setWidths] = useState<number[] | null>(null)   // null = 未拖过 → 用默认比例
// 渲染：格 1..3 用 style={{ width: w }}（flex-basis 定宽），格 4 = flex: 1 吸收剩余
```

- 只存前 3 格宽度，**格 4 = `flex: 1; min-width: 240px`** 永远吃掉剩余空间（拖拽条 3 拖动时同理：格 3 定宽变化、格 4 弹性吸收）；
- 初始（未拖拽）：格 1 = 168，格 2/3 按剩余空间 `1.15 : 0.9` 分配，格 4 弹性；窗口 resize 未拖时按比例重算（拖过则锁定用户值）；
- **组件化**：新增通用 hook `useResizableColumns`（管理 widths / 三根条的事件绑定 / 双击重置 / minmax 钳制），不侵入四个格子组件内部。

```tsx
interface ResizerSpec { defaultWidth: number; minWidth: number }

// ProjectDetail 内（示意）
const [widths, handlers] = useResizableColumns([
  { defaultWidth: 168, minWidth: 168 },   // 格 1 会话列表（固定起步宽，可拖宽）
  { defaultWidth: 260, minWidth: 260 },   // 格 2 会话详情
  { defaultWidth: 200, minWidth: 200 },   // 格 3 Terminal
])                                       // 格 4 = flex 吸收，无独立 width
// <div className="cell-resizer" onDoubleClick={handlers.reset} onMouseDown={(e) => handlers.start(0, e)} />
```

**验证要点**（补充进第 11 节）：三根条均可拖、相邻两格此消彼长、min 触底不塌陷、双击回默认、拖拽中无文本选中、格 4 始终吃满余量。

## 3. 状态上提（关键决策）

第 1、2、3 格共享「当前会话」状态 → **`activeSessionId` 及其行为从 ChatPane 上提到 ProjectDetail**：

- ProjectDetail 新增 state：`activeSessionId`（默认 order 最大）、派生 `activeSession/job/run/waiting/unreadTotal`；
- `selectSession`（切会话 + 清未读）、`handleNewSession`（新建 manual 置顶切换）上提；
- `focusJobId` / `sessionFocus` 的 useEffect 上提（通知跳转、工作流「打开本步骤会话」联动链路不变）；
- ChatPane 改为**受控组件**：接收 `activeSession` + `onSelectSession` + `onNewSession`，专注渲染消息流与插话；
- 手动会话插话逻辑（append 人消息 + 1.5s ADE 假回应 + Terminal 日志行）留在 ChatPane（它持有 onUpdateProject/engine）。

## 4. TerminalPane（格 3）设计

### 4.1 数据模型（`data/projects.ts` 新增）

```ts
/** Terminal 日志行（agent 工具调用日志） */
export interface TerminalLog {
  id: string
  /** HH:mm:ss 时间戳 */
  time: string
  /** cmd = 命令行（❯ 提示符）/ out = 普通输出 / ok = 成功（绿）/ err = 失败（红）/ info = 事件（青） */
  kind: 'cmd' | 'out' | 'ok' | 'err' | 'info'
  text: string
}
```

- `ProjectSession` 增加可选字段 `logs?: TerminalLog[]`（manual 会话预置 Mock；新建会话空）；
- 新增导出 `runLogsOf(run: JobRun): TerminalLog[]`：**从 run.messages 实时派生** auto 会话日志（引擎零改动）：
  - 系统消息（运行开始/结束/人工处理）→ `info`；
  - ADE「开始执行：X」→ `cmd`（`tool:step --name "X"` 风格）；
  - ADE 带 result 的「X完成。」→ `ok`（含产物文件数与 URL）；
  - 人插话 → `cmd`（`ask` 风格）+ ADE 回应 → `out`。

### 4.2 组件（`TerminalPane.tsx` + `.css`）

```tsx
interface TerminalPaneProps {
  project: Project
  activeSession: ProjectSession | null
}
```

- 日志源：auto 会话 → `useMemo(() => runLogsOf(run))`（引擎推进时自动增长）；manual → `session.logs ?? []`；
- **日志格视觉（浅色，与格子语言一致）**：**白底（与其他格子一致，无 #fafafa 差异底色）**、`SF Mono/Menlo/Consolas` 11.5px、行距 1.7、`❯` 提示符与 cmd 行用**深青蓝**（替代黑底终端的绿色）、kind 着色走浅底配色（cmd 深青蓝 / out 灰 / ok 绿 / err 红 / info 蓝）、行首浅灰时间戳小列、行 hover 微灰底；**头部无交通灯三点装饰**（仅 `ADE 工具日志` 标题 + 当前会话名）；
- 吸底跟随：`stickBottom` ref（同消息流逻辑，用户上翻时停止跟随）；
- 空态：`❯ 等待 agent 调用工具…`（闪烁光标动画）。

### 4.3 manual 会话插话联动（ChatPane.handleSend）

插话时向 `session.logs` append：`cmd: 用户插话 {text}` → ADE 假回应后 append `out` 行（与消息 append 同一次 onUpdateProject 事务）。

## 5. SessionRail（格 1）设计

- 常驻列表：条目 = **左侧圆形头像（背景色 + 2 个字，取会话名前 2 字，auto/manual 会话各配色）** + 右侧两行文字（会话名 ellipsis + 未读徽标 / 运行状态徽标 + 来源副文案），当前会话高亮，`order` 降序；
- 头部：**`项目名 · 会话`**（项目名次级着色，单行省略）+ 总数徽标；**右上角 icon 组**：✎ 编辑项目（铅笔 icon，title「编辑项目」，弹窗入口自格 2 迁入）+ ＋ 新会话（均无文字；无「N 未读」字样——未读只体现在条目小徽标上）；
- **无底部区域**（原「＋ 新对话」按钮与「任务的每个阶段 = 独立会话」提示移除，新建会话收口到头部 ＋ icon）；
- props：`sessions / activeSessionId / onSelect / onNewSession / onOpenEdit`（纯展示 + 回调，无内部状态）。
