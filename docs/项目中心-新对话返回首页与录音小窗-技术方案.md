# 「新对话」返回首页 + 输入卡片「录音」小窗

> 创建日期：2026-10-20
> 更新日期：2026-10-20（入口改 @ 菜单「长录音」；小窗锚定主区右上角 + 可拖动；停止后小窗内出「加入输入框」btn，点击才把录音.mp3 文件条放进输入框；「放大」改「详情」；已停止态补「继续」录音 btn）

## 1. 需求

1. **回首页入口**：当前从首页进入「项目中心 / 项目详情」后无法返回首页会话框，只能刷新页面。侧边栏「新对话」按钮目前是静态按钮，需改为点击后**回到首页视图**（即带会话输入框的 home）。
2. **录音功能（仅小窗，本期无独立录音页）**：首页会话输入卡片**@ 引用菜单**里加「长录音」入口：
   - 点击后打开**录音小窗，锚定主内容区右上角**（预览/面板工具 icon 下方），且**可自由拖动**；
   - 显示**正在录音的进度**（计时 + 音柱动效）；转写区**只展示最近一句**（替换更新）；
   - 「停止」后小窗不消失，进入**已停止态**：显示文件名「录音.mp3 · mm:ss」+「加入输入框」按钮 + 「×」关闭；点「加入输入框」才把**录音.mp3 文件条**放进输入卡片（textarea 上方附件条）；
   - 「详情」按钮（原「放大」改名）：占位禁用（独立录音详情页后续接入）。

## 2. 现状与差距

| 项 | 现状 | 差距 |
|---|---|---|
| 侧边栏「新对话」 | `Sidebar.tsx` 静态 `<button>`，无 onClick | 无法回到 home 视图 |
| App 视图状态机 | `view: home / project-center / project-detail`，只有「项目中心」能进入 | 缺一条回 home 的通道 |
| ChatInput 工具栏 | + / 斜杠 / @ / 模式下拉 / 发送按钮 | 无录音入口 |
| 录音小窗 | 不存在 | 全新增组件 |

## 3. 技术方案

### 3.1 「新对话」回首页

- `App.tsx`：`Sidebar` 新增 prop `onNewChat={() => setView({ type: 'home' })}`；
- `Sidebar.tsx`：「新对话」按钮绑定 `onNewChat`；
- 已在首页时点击「新对话」无副作用（重复 set 同值视图，仅重渲染）；从详情页/项目中心点击则回到首页会话框；
- `projectCenterActive` 传值保持 `view.type !== 'home'` 不变（回首页后项目中心菜单自动取消选中态，现逻辑已兼容）。

### 3.2 录音小窗（新组件 `RecordingWidget`）

**入口**：`ChatInput` 工具栏的 **@ 引用按钮改为弹出菜单**（复用 `Dropdown` 的菜单视觉：白底圆角 10px + 阴影 + item hover），菜单项「**长录音**」（带麦克风 icon）；点击开启录音并打开小窗（菜单关闭）。独立麦克风按钮移除。

**小窗形态**（挂在窗口坐标系，默认锚定主区右上角，可拖动）：

```
┌─ 录音中（头部可拖动）─────┐   ┌─ 已停止（点停止后）───────────┐
│ ● 正在录音        00:23   │   │ 🎙 录音.mp3 · 00:23          │
│ ◼◼◼◼◼◼ 音柱动效条         │   │ 最近一句转写（定格）           │
│ 最近一句：把项目中心…      │   │ [🎤继续] [加入输入框] [详情×] │
│ [⏹ 停止]         [详情]   │   └──────────────────────────────┘
└────────────────────────────┘   （继续 = 恢复同段录音计时）
```

- **定位**：`position: fixed`，默认**主区右上角**（`top: 60px; right: 24px`，预览/面板工具 icon 下方同列）；**头部区域为拖拽把手**——`mousedown` + `mousemove` 更新 `left/top`，拖动中 `user-select: none`，松手保留位置；
- **进度**：秒表计时（`mm:ss`，1s interval），红色呼吸圆点 + 音柱动效条；停止后动效静止（呼吸点变灰、音柱定格）；
- **转写（最近一句）**：Mock 句子池按计时逐句推进，**只渲染最新一句**（淡入替换）；停止后定格；
- **「停止」→ 已停止态（小窗不关闭）**：文件行「🎙 录音.mp3 · mm:ss」+ 定格的转写句 + 操作行「**继续**」「加入输入框」「详情」+「×」；
- **「继续」**：恢复**同一段录音**继续计时（计时从暂停处接着走，非重新归零；动效恢复）；
- **「加入输入框」**：点击 → 把**录音.mp3 附件条**加入输入卡片（见 3.3）；小窗保留（可重复点击幂等去重，也可「×」关闭）；
- **「详情」按钮（占位）**：禁用态 + tooltip「录音详情开发中」（独立详情页后续接入）；
- **「×」**：关闭并丢弃本轮小窗；
- **真实麦克风**：mock 环境静默降级为纯 Mock 计时（不报错、不打断）。

### 3.3 「加入输入框」→ 录音.mp3 附件条（输入卡片内）

点小窗「加入输入框」后，输入卡片 textarea 上方出现**文件附件条**：

```
┌──────────────────────────────────────────────┐
│ 🎙 录音.mp3 · 00:23 · 168KB          × 移除  │  ← 附件条
│ ┌──────────────────────────────────────────┐ │
│ │ 可向 Loom 询问任何事                      │ │
│ └──────────────────────────────────────────┘ │
│ [+] [/] [@▾]      …toolbar…          [发送]  │
└──────────────────────────────────────────────┘
```

- **数据结构**：`ChatInput` state `recordingFile: { id; name: '录音.mp3'; seconds; size } | null`（附件条）+ `recordingId`（录音中会话）；
- **附件条内容**：红色麦克风 icon + `录音.mp3` + 时长 + Mock 大小 + 「×」移除；
- 同一录音 id 重复点「加入输入框」不堆叠（去重）；新一轮录音加入后**替换**旧附件条（同时至多一条，Mock 语义）。

## 4. 交互细节

1. 点 @ 按钮 → 弹菜单「长录音」→ 开启录音，小窗出现于主区右上角（fixed）；
2. 计时跳动 + 音柱动效；转写区只显示最近一句（替换更新）；
3. **拖动**：按住小窗头部拖动可改位置，松手保留；
4. 点「停止」→ 小窗切已停止态（动效静止、出文件行与操作按钮）；
5. 已停止态点「继续」→ 同一段录音恢复计时（接着走，不归零），动效恢复；
6. 已停止态点「加入输入框」→ 输入卡片出现 **录音.mp3 附件条**（textarea 上方）；重复点不堆叠；「×」可移除附件条；
7. 小窗「详情」= 占位禁用（tooltip「录音详情开发中」）；「×」关闭小窗；
8. 已停止后再点「长录音」= 新一轮（旧小窗被替换，重新计时）；
9. 录音中再点「长录音」= 无效（防重复开启）。

## 5. 不做的事（明确边界）

- **不做独立录音详情页**（「详情」btn 留占位禁用态，后续需求再接入）；
- 不做真实语音识别 / 真实音频文件（Mock 文案 + Mock 大小）；
- 不做多条录音附件并存（同卡片同时至多一条，新一轮替换旧的）；
- 小窗位置不做持久化（刷新后回默认右上角）；
- 「新对话」只做视图切换，不清理任何项目数据。
